账户页 · 7 个问题

money_accounts_section.dart（1651 行）

  1. 1
    顶部只有「资产合计」，负债不可见必须_summaryText 只累加 isAssetLike 账户的 balanceMinor。用户看得到「资产 ¥58,200」，看不到自己欠了多少，净资产更是没有。
  2. 2
    单张卡片最多 8 层信息必须图标 / 名称 / 类型·币种 / 账单日·还款日 / 3 个账单徽章 / 说明 / 本月对比长句 / 余额 / 额度明细 / 隐私按钮。手机上每张卡要占掉近半个屏幕。
  3. 3
    信用账户算不出「用了多少」必须「额度 ¥20,000 · 已入账 ¥5,860 · 冻结 ¥0」挤在一行 11px 小字里，没有进度条，用户得自己做除法。
  4. 4
    排序能力藏起来了支持按更新时间 / 创建时间 / 名称 / 余额 / 类型排序，入口是一个筛选图标。既不知道能排序，也看不出当前是按什么排的。
  5. 5
    操作只能靠左滑编辑 / 停用 / 删除挂在 AppSwipeActionTile 上。左滑是常见手势，但没有任何视觉提示；点整行是「看流水」，于是「怎么改账户名」对第一次用的人是个谜。
  6. 6
    分组是「三选一」资产 / 信用负债 / 停用 只能看一个，切到信用组就看不到资产总额，无法对照。
  7. 7
    「隐藏金额」跨用户串号按账户 id 存进 SharedPreferences 的单一 key account_hidden_ids（逗号拼接），没有 userId 隔离。

流水页 · 7 个问题

money_transactions_section.dart（2012 行）

  1. 1
    没有搜索框必须关键词和商户搜索在筛选抽屉里排第 8、9 位。要「点图标 → 展开抽屉 → 往下翻 → 找到输入框」四步才能开始打字，而这是流水页最高频的动作。
  2. 2
    筛选之后没有合计必须只有「从账户点进来」时才显示 _AccountTransactionSummaryPanel。按分类 / 日期 / 关键词筛选后，「这段时间一共花了多少」这个最核心的问题没有答案。
  3. 3
    完全不支持排序必须仓储层硬编码 transactionAt DESC, createdAt DESC，MoneyTransactionQuery 里连排序字段都没有。想「按金额从大到小看本月支出」做不到。
  4. 4
    类型切换不是常驻的全部 / 支出 / 收入 / 转账 在抽屉里。手机上这是第二高频的筛选，应该是一排按钮。
  5. 5
    筛选面板是 9 控件的长表单预算 / 类型 / 账户 / 支付方式 / 分类 / 子分类 / 日期区间 / 关键词 / 商户，全在一个底部抽屉里，手机上要翻很久。
  6. 6
    回看历史很费劲分页 20 条、滚动加载，没有月份跳转。想看上上个月只能一直往上滚。
  7. 7
    没有批量操作没有多选。月初整理上个月的零散记录只能一条条点开改。

改版要点

两条主线：把「藏在抽屉里的能力」搬到台面上；把「一层层读」的信息改成一眼扫

区块优先级做法与理由
流水：常驻搜索框必须搜索框固定在首屏第一行，进入页面就能直接打字。带动画展开，不占额外高度。
流水：结果汇总条必须只要有筛选条件就显示「共 24 笔 · 支出 ¥3,240 · 收入 ¥10,000 · 净 +¥6,760」，右侧一键清除。
流水：类型分段常驻必须全部 / 支出 / 收入 / 转账 做成首屏一排按钮，替代抽屉里的下拉。
流水：日期快捷区间高本周 / 本月 / 上月 / 自定义 四个胶囊，覆盖绝大多数看账场景，不用每次开日期选择器。
流水：排序高时间 ↓ / 金额 ↓ / 金额 ↑。需要给 MoneyTransactionQuery 加排序字段并下沉到仓储层。
流水：月份跳转中日期区间里加「选择月份」，一次跳到某个月的首尾，替代无限上滚。
流水：长按多选中长按进入多选，底部出现批量条（删除 / 改分类）。属于后续迭代。
账户：净资产 Hero必须顶部给净资产（资产 − 负债）+ 资产 / 负债 / 信用已用三段拆分与占比条。
账户：卡片重排必须从 8 层压到 4 层：主行（图标 + 名称 + ⋯）/ 余额行 / 额度条（仅信用）/ 本月收支行。
账户：额度进度条必须信用账户把「已用 / 额度」做成进度条 + 数字，超过 80% 转警示色。
账户：⋯ 操作菜单高行尾固定一个 ⋯（编辑 / 停用 / 删除 / 查看流水）。左滑保留为快捷方式，但不再是唯一入口。
账户：分组 chips 带金额高资产 / 信用负债 / 停用 并排，每个显示自己的合计，同屏可对照。
账户：排序入口外露中工具栏上直接显示当前排序（默认「最近更新」），点击切换。
账户：品牌色图标低按类型给品牌色（支付宝蓝、微信绿、招行红…），一列账户能靠颜色区分。
两者：隐私开关中顺手修掉跨用户串号：改为按 userId 存，或迁移到 user_preferences。

建议实施顺序

前三步都是「不加新功能、只让已有能力可见」——不碰数据层，风险最低

顺序改动为什么先做这个
①流水页：常驻搜索框 + 类型分段 + 日期快捷区间纯布局改动，直接复用现有 _keywordFilter / _typeFilter / 日期参数，不动数据层。收益最大。
②流水页：筛选结果汇总条数据已在列表里，前端累加即可（见下方待确认第 1 条）。
③账户页：卡片重排 + 额度进度条 + ⋯ 菜单纯展示层。卡片高度能砍掉近一半，一屏从 2 张变 4 张。
④账户页：净资产 Hero + 分组 chips复用 currentUserBookkeepingOverviewProvider 已有的 assetMinor / liabilityMinor，只需新增一个聚合 provider。
⑤账户页：排序入口外露 + 品牌色图标纯展示层。
⑥流水页：排序要动数据层：MoneyTransactionQuery 加排序字段 + 仓储 orderBy 分支，可能要补索引。
⑦流水页：长按多选 / 批量操作改动最大，建议单独一轮。
