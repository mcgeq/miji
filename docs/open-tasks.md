### ⛔ 已排除

- G6 支付通知捕获（不申请通知读取权限）
- 短信解析（iOS 读不到第三方短信，Android 审核风险高）
- 银行 API 直连（国内无面向个人的开放接口）
- 端侧跑多模态大模型（体积 / 性能 / 多端不可用）

## 五、产品决策（🟡 待拍板）

| # | 问题 | 现状 / 建议 |
| --- | --- | --- |
| 1 | 全局 FAB 是否只留流水类动作 | 九宫格含账户 / 预算 / 分期等跨页动作；砍掉等于能力缩减，属产品取舍 |
