Miji · Bookkeeping Refactor

记账模块 UI 重构预览

三个关键界面的「改造前 / 改造后」并排对照。所有改动都只重组展示层，不动数据层——复用现有 Provider 与仓储接口。左滑右侧手机可以真实滚动，感受首屏能多看到多少内容。

这次重构解决什么

核心判断：功能已经够全，问题是同一批信息在多处重复铺开，把高频动线的首屏挤没了。

01 · 首屏 控制区从 6 段压到 2 段 搜索、操作行、状态 chips、日期 chips、汇总条、banner 六层堆叠 → 一行搜索 + 一行生效筛选，汇总条吸底。
02 · 列表 卡片去掉重复的日期 分组头已经写了「今天 / 昨天」，卡内再写一次是纯冗余。卡内只留时间，一屏多出近一整行。
03 · 状态 筛选不再整屏闪骨架 保留旧列表 + 顶部细进度条，只有首次进入才用骨架。点筛选 chip 不再是「白一下」。
04 · 空态 区分「无数据」和「筛不出来」 有筛选时给「清除筛选」主按钮，没筛选才引导记账——现在是两种情况共用同一句文案。
05 · 表单 高频字段提到前面 「名称」原来排在账户、分类、日期之前；备注还被折叠进「更多信息」。调整后三个高频字段都在首屏。
06 · 自动记账 三层横幅合并、预览下沉 冲突 + 接管失效 + 分期预览合并成一个可折叠提醒区，分期预览降级为列表底部一行「相关」链接。

改动 ↔ 代码位置对照

全部是展示层重组，复用现有 Provider 与仓储接口，不新增数据查询

改动涉及文件做法
流水页控制区折叠 transactions/money_transactions_section.dart 状态 chips 与日期 chips 合并进一行默认折叠的筛选条（无生效条件时整块不占高度）；导出 / 回收站收进 ⋯。⚠️ 画稿里「下钻上下文横幅缩成可关闭 chip」这一条没有实现，上下文仍只在筛选抽屉里显示。
汇总条改吸底 money_transactions_section.dart 从列表上方的普通区块移到列表 Expanded 之后的 Column 末位（money_transactions_section.dart:454-467）：常驻可见、占位不覆盖列表；宽屏下右侧预留约 64 给右下角的 FAB。
卡片日期去重 transactions/transaction_card.dart 卡内日期由 MM-DD HH:mm 改为只渲染 HH:mm，跨天信息交给分组头。
筛选不闪骨架 money_transactions_section.dart _refreshFromFilterChange 不再清空列表，改为保留旧数据 + 顶部细进度条。
空态分流 money_transactions_section.dart 复用已有 _hasActiveFilters，有筛选时渲染「无匹配 + 清除筛选」分支。
表单字段顺序 transactions/transaction_form_dialog.dart 交换「名称」与「分类 / 账户」的位置；备注从「更多信息」提到顶层。
自动记账横幅合并 auto_posting/money_auto_postings_section.dart 冲突横幅 + 接管失效横幅合并为 _AutoPostingAttentionPanel：折叠态一行「需要处理 N 项」，展开才铺出条目（AnimatedSize）。
分期预览下沉 money_auto_postings_section.dart 删掉 _UpcomingInstallmentPreview，改为列表底部一行 _RelatedInstallmentsLink，点击切到「分期」面板。
术语统一 transactions / statistics / accounts / budgets / installments 四个都叫「类型」的下拉按概念拆开：交易类型 / 统计类型 / 账户类型 / 追踪类型；支付渠道统一；「子分配」收敛为「分配」。标签变长要连带加宽（label 就是占位文案，单行省略）。
空态 CTA 带文字 账户 / 预算 / 自动记账 / 分期 七处空态按钮由纯图标改为 FilledButton.icon / OutlinedButton.icon。页面级常驻的 ＋ 仍是图标（同排还有排序 / 隐藏金额 / 筛选）。
新增入口统一 money_accounts_section.dart、money_auto_postings_section.dart 四个页面级 ＋ 统一为 filled + Icons.add_rounded。FAB 九宫格未动。
滑动与菜单二选一 budget_card.dart、money_accounts_section.dart 预算卡片左滑 5→2、账户卡片左滑 3→2，只留编辑 / 删除；移出的动作都已在 ⋯ 菜单或卡片内常驻按钮里。
转账表单对齐 transfer_form_dialog.dart、transaction_form_dialog.dart 补 autofocus；新增 TransferFormSubmit 回调以支持「保存并继续」（与记一笔同构，未传时保持原 pop 契约）；记一笔日期快捷项改为编辑态也显示。
表单字段顺序 + 备注提到顶层 transaction_form_dialog.dart 重排为 金额 → 分类 → 账户 → 日期 → 名称 → 备注 → 状态 → 支付方式 → 更多。备注从「更多信息」搬出，minLines 2→1（空着只占一行）。
统计页签 + 看板分节 money_statistics_section.dart、money_dashboard_editor_sheet.dart 页签补分组图标 + 组内卡片数角标，高度 32→40；看板编辑器 22 项按当前排序动态插分组小标题（拖拽后不会错位）。
账户分组 chips 带金额 money_accounts_section.dart chips 由「名称 · 数量」改为「名称 · 数量 · 金额」（紧凑格式）。停用组不给金额；多币种时也不给（直接相加是错的）。
标签筛选入口 money_transactions_section.dart 展开态筛选条补「标签」多选（与状态 / 日期同级）。原来标签筛选只能从统计页下钻带过来，列表里没有入口。
复制入口 transaction_card.dart 流水卡片左滑补「复制」（复用详情里的「再来一笔」）。原来要先点开详情。

落地状态：批次一（流水页：控制区折叠 / 吸底汇总 / 不闪骨架 / 空态分流 / 卡片日期）、批次二（自动记账页：横幅合并 / 预览下沉）、批次三（术语统一 / 空态 CTA 带文字 / 新增入口统一 / 滑动与菜单二选一 / 转账表单对齐）、批次四（表单字段顺序 + 备注提到顶层 / 统计页签与看板分节 / 账户分组 chips 带金额 / 标签筛选入口 / 复制入口）均已实现。两处判定为「不需要做」：P0-1 的「下钻上下文 chip」已由批次一的生效条件 chips 覆盖；P2-3 的「搜索框 hint 与商家不符」原文判断过时——关键词谓词本来就已经 LIKE 了 merchant。
