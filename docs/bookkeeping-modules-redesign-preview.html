1.1 八个面板挤在一个只显示图标的横条里阻塞

bookkeeping_page.dart:70-133

  • 1
    移动端放不下，要横滑minSegmentWidth:44 × 8 = 352px，而 360dp 手机上 AppPageFrame 左右各留 12px，可用只有 336px → 首屏必然出现横向滚动，末尾的「自动记账 / 提醒」被裁掉一截，不滑一下根本看不到还有两个模块（输入框旁边的面板也一样：单个分段只有 44×44 的点击区，且没有文字）。
  • 2
    没有文字，只能长按看提示showLabels:false，标签只作为 Tooltip；手机上要长按才出现，且一次只显示一个。图标语义还互相重叠：query_stats=统计、category=分类、flag=预算、event_repeat=自动记账、notifications_active=提醒，新用户基本靠猜。

1.2 面板状态不进 URL，返回键会直接退出记账页

app_router.dart:149-153 · bookkeeping_page.dart:41-58

  • 1
    路由已经支持 ?section=，但只当初始值initState/didUpdateWidget 读取后写入 setState，切面板不写回路由。Web 上刷新、浏览器后退、分享链接都会掉回「账户」。
  • 2
    系统返回键会直接退出记账页面板切换是纯 setState，不产生路由历史。所以「统计页点分类 → 跳到流水 → 按返回键」不会回到统计页，而是直接退出记账模块；从首页或通知带 ?section= 跳进来之后，返回栈也不对。

1.3 「总览」已经在首页，记账页反而接不住它

home_page.dart:250-350 · home_page.dart:491-498

  • 1
    首页就是总览，不需要第二个首页已经有一整套总览：问候 + 连续记账天数、HomeBalanceHeroCard（本月还能花 + 今日支出 + 分类预算）、快捷记账、洞察条、紧急提醒、今日行动 / 净资产 tile、周趋势、分类结构、最近流水。所以记账页不应该再做一个「总览」面板，旧 BookkeepingOverviewSection 应该删除而不是复活。

    而默认种子总有分类money_seed_data.dart 里有整套餐饮/交通/购物…分类，所以空态永远不会出现。
  • 3
    全仓只有一个调用点createCategory 的调用方就是那个空态按钮，也没有快捷动作入口。结论：用户永远无法新增分类（子分类可以，因为父级行上有「＋」）。

2.2 预算：有预算之后，新增按钮消失阻塞

money_budgets_section.dart:75-135

  • 1
    非空分支只有筛选触发器和列表budgets.isEmpty 时走 _EmptyBudgetsPanel（带「＋」），有数据后整行按钮消失，只能去全局 FAB 的九宫格找「预算」。
  • 2
    筛选没有生效提示AppFilterSheetTrigger 没有传 hasActiveFilters（账户页与流水页都传了），也没有结果计数，筛完不知道筛没筛。

2.3 分期：onCreate 是死参数阻塞

money_installments_section.dart:59, 200-208

  • 1
    声明了却从没用过_MoneyInstallmentsContent 接收 required this.onCreate，但 build 里从未引用（grep 全文件只有构造与赋值两处）。页面顶部只有一个右对齐的占位，实际没有按钮。
  • 2
    三个空态都没有动作「没有可用信用账户」「没有支出分类」「没有分期计划」三个 AppEmptyState 都没传 action，而第一个本该直接引导去「新增信用账户」。

2.4 账单提醒：功能完全没有入口阻塞

money_bill_reminders_section.dart 无引用 · money_reminder_center_section.dart

  • 1
    提醒中心不能新建，只能处理它只有「完成 / 延后一天 / 忽略」三个动作，数据来自预算、信用卡账单、分期、周期支出、账单提醒五个来源——但账单提醒这个来源没有任何地方能创建。
  • 2
    下游已有依赖统计页「待付账单」卡（money_upcoming_bills_card.dart）、首页紧急提醒、本地通知服务（money_bill_reminder_notification_service.dart）都在消费这份数据，空转。

2.5 分类图标渲染成英文单词阻塞

category_selector.dart:150-190

  • 1
    把图标名当文本画出来了_SelectorItem 里 iconText == null ? Icon(fallback) : Text(iconText)，而库里 icon 字段存的是 Material 图标名（restaurant / breakfast_dining / category / emoji_events）。于是分类/子分类下拉菜单每一项前面都出现 restaurant、breakfast_dining 这样的英文单词。
  • 2
    入口没有图标可用分类卡自身固定用 Icons.category_rounded，颜色是唯一区分维度；新建分类时 icon 被硬编码成 'category'。修法见预览 4：用「颜色圆点 + 可选 emoji」两轨道。

2.6 流水汇总条右侧的「筛选」是空按钮阻塞

money_transactions_section.dart · _TransactionSummaryBar

  • 1
    onPressed: () {}按钮在「有筛选条件」时出现，文案是「筛选」，但点了完全没有反应。要么改成「清除筛选」（真正有用），要么删掉。
  • 2
    搜索提示与实际能力不符输入框提示「搜索分类、商户、备注…」，而仓储层 keyword 只 LIKE description | notes（transactions.dart:1509-1515）。按商户名搜不到，商户搜索在抽屉里是另一个输入框。

三 · 交互与效率（6）

功能都在，但每一步都比同类产品多一次点击

3.1 统计页：5 个分页只有圆点

money_statistics_section.dart:1070-1120 · _PageDots

  • 1
    不知道后面还有什么5 页分别是 概览 / 消费 / 渠道 / 预算 / 账户，全部只显示圆点。分页里一多半卡片（渠道、预算趋势、净资产趋势、待付账单、未来现金流、成员参与、月度报表）用户根本不知道存在。
  • 2
    筛选没有状态、没有重置_StatisticsFilterStrip 没有重置按钮（预算页有），AppFilterSheetTrigger 也没传 hasActiveFilters。「账户=招行 + 渠道=支付宝」和「无筛选」在界面上长得一模一样。

3.2 记一笔：分类要两级下拉，金额用系统键盘

transaction_form_dialog.dart · category_selector.dart

  • 1
    分类是「分类 → 子分类」两个下拉记账软件最高频的动作是「餐饮 / 午餐」，现在是两次展开 + 两次搜索列表。没有图标网格、没有常用置顶、没有最近使用。
  • 2
    没有自定义数字键盘AppAmountField 用系统键盘（numberWithOptions）。没有「+ −」连算、没有「再记一笔」；表单底部只有「取消 / 创建」。

3.3 流水卡不用分类颜色与图标

transaction_card.dart · _icon

  • 1
    图标只区分收/支/转账分类退化成标题文字，颜色也没有用到（分类表里本来就有 color 字段）。一屏流水里找「餐饮」和「交通」全靠读字，扫读性差。
  • 2
    当天只有支出/收入，没有净额_DayGroupHeader 显示「支出 ¥x 收入 ¥y」，没有当日净额；也没用「本周合计」之类的周维度。

3.4 预算卡 9 层信息，缺决策数字

budget_card.dart

  • 1
    一屏只能看 2 张名称 / 范围 / 周期 / 账本徽章 / 进度条 / 已用 / 剩余 / 目标 / 分配概览（4 个子项）/ 阈值提示。
  • 2
    缺「日均可用」与「距超支还剩几天」用户真正要的是「这个月每天还能花多少」。数据都在（periodEnd、remainingAmountMinor），只是没算没显示。

3.5 提醒中心不分组、不能批量

money_reminder_center_section.dart:80-100

  • 1
    逾期和「下个月」混在一条列表里卡片内用颜色区分优先级，但顺序不变、也不分组。逾期 3 笔被埋在 20 条里。
  • 2
    操作只有左滑完成 / 延后 / 忽略都挂在 AppSwipeActionTile 上，没有行内按钮，也没有多选批量「全部忽略本月订阅类提醒」。

3.6 分期与自动记账缺少时间语义

money_installments_section.dart · money_auto_postings_section.dart

  • 1
    分期「下一期」只给日期显示 11-15，不给「还剩 3 天」，用户要自己算；也没有「提前还清 / 一次性结清」入口，只能一期一期点入账。
  • 2
    自动记账没有「下次执行」卡片上是「从 2024-01-01 起 · 每月 5 日 08:00」，要自己推算下一次；运行历史占 2 行，比「下次执行」次要。

四 · 一致性与工程债（5）

同类交互在四个页面有四种做法，长期维护成本高

4.1 四套筛选交互

页面形态生效提示 / 重置
账户header chips + 抽屉有 hasActiveFilters；重置在抽屉里
流水常驻搜索 + 分段 + 日期胶囊 + 抽屉有角标；重置按钮是空的
统计只有抽屉无提示、无重置
预算只有抽屉无提示；重置在抽屉里
提醒中心AppFilterStrip chips无（历史筛选）

4.2 新增入口位置不统一

  • 位
    账户页header 行尾「＋」（filled 圆形图标按钮）
  • 位
    自动记账 / 账单提醒（旧）内容区右上角右对齐单独一行
  • 位
    预算 / 分类 / 分期没有（只在空态里）
  • ?
    建议统一为「页面级工具条右侧＋」，与 AppPageToolbar 对齐；空态额外再给一个带文案的主按钮。

4.3 空态不统一

  • 有
    账户 / 流水 / 预算 / 自动记账 / 分类（空）/ 统计（无数据）带 message + action 或只有标题。
  • 无
    分期三个空态、提醒中心两个空态只有标题，没有下一步动作，也不知道该去哪。

4.4 币种与金额格式

  • 1
    日期分组头硬编码 CNY_DayGroupHeader 里 formatMoneyMinor(expenseMinor, 'CNY')，多币种用户的日元流水会被标成 ¥ 人民币符号。
  • 2
    待付账单卡也用全局默认币种_Bucket 用 defaultMoneyCurrencyCode 而不是账单自己的 currencyCode。
  • 3
    JPY/KRW 永远两位小数formatMoneyMinor 固定 decimalDigits: 2，¥1,200.00 日元在中文语境里是错的。

4.5 待付账单两处口径不一致

money_upcoming_bills_card.dart:36-56

  • 1
    用原始 dueDate 而不是生效日期提醒中心与通知服务都走 _effectiveDueDate（处理按周/月/年重复），统计卡直接用 dueDate，重复提醒会算错窗口。
  • 2
    「最近待付」没有过滤已逾期排序取前 5 时不过滤 dueDate < now，一条两个月前的旧提醒会一直占据首位并显示「今天」。

八 · 建议实施顺序

第一阶段不碰数据层，全部是「让已有能力可见」，可以一次提交完

顺序改动为什么先做这个
①分类/预算/分期补新增入口纯展示层。分类那条是永久性功能缺失，优先级最高。
②提醒中心补「＋」，抽出账单提醒表单让一个已实现但不可达的功能重新可用；旧文件的列表部分直接丢弃，净减代码。
③流水汇总条「筛选」→「清除筛选」；搜索提示对齐一行改动，消除一个「点了没反应」。
④分类图标渲染修复（映射或 emoji）影响所有下拉菜单，属于可见的观感 bug，越早越好。
⑤统计页分页标签 + 统计/预算筛选状态纯展示层，但能让「渠道 / 预算 / 账户」三页重新被发现——投入产出比最高的一项。
⑥预算汇总条 + 日均可用；流水卡分类颜色纯展示层，把已有数据算成决策信息。
⑦首页净资产 tile 死链修复 + 默认落点一行死链修复 + 一个默认值决定；放在纯展示改动之后。
⑧导航写回 URL / 导航结构动 BookkeepingPage 核心，单独一轮 + 补测试。
⑨记一笔：分类网格 + 数字键盘改动最大（新组件 + 表单提交契约），建议与表单相关测试一起做。
⑩币种显示 / 待付账单口径统一收益明确但只在多币种 / 重复提醒场景暴露，最后做。
