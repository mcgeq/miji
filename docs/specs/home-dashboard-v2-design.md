## 一、现状盘点

首页当前的结构（`lib/features/home/presentation/home_page.dart`）：

| 顺序 | 区块 | 归属模块 | 数据 |
| --- | --- | --- | --- |
| 1 | 问候头 + 连续天数 | 记账 | `homeStreakProvider` |
| 2 | 本月预算 / 趋势 / 日历（三合一卡） | 记账 | 6 个 provider |
| 3 | 洞察条 | 记账 | `homeInsightProvider` |
| 4 | 需要关注（提醒条） | **仅记账** | `currentUserPendingReminderCenterItemsProvider` |
| 5 | 今日行动小卡 | 打卡待办 | `todayActionItemsProvider` |
| 6 | 净资产小卡 | 记账 | `homeNetAssetSummaryProvider` |
| 7 | 健康窄条（一行） | 健康 | `homeHealthHintProvider` |
| 8 | 分类结构 | 记账 | `homeCategoryStructureProvider` |
| 9 | 最近流水 | 记账 | `homeRecentTransactionsProvider` |
| 10 | 语录 | — | 静态 |

**问题清单**

1. **记账独占首页**。10 个区块里 6 个是钱（2/3/4/6/8/9），真正跨模块的只有「今日行动卡」和「健康窄条」两张小卡，还都是可选隐藏、默认健康关闭。
2. **待办数据太浅**。`HomeTodayActionTile` 只显示 `已完成/总数` + `下一件` 一行，看不到待办列表、逾期、优先级；习惯只以「下一件」名义出现，没有打卡入口、没有连续天数。想做一件事（勾掉一个待办）必须跳到 GTD 页。
3. **健康数据太浅**。`buildHomeHealthHint` 只输出标题 + 一行 detail：`经期第 3 天` / `距下次经期还有 12 天`。**没有**周期阶段（卵泡/排卵/黄体/PMS）、没有今日记录状态明细（心情/睡眠/饮水/体重）、没有未来预测窗口。
4. **提醒不跨模块**。`HomeAlertsStrip` 只吃记账提醒（账单/预算/分期）。待办逾期、打卡提醒、经期/排卵提醒都不在首页。
5. **空态与开关体验差**。
   - 健康开关默认关，且只有「有没有历史」一个门槛，未开启追踪时整条消失，用户不知道首页还能显示健康。
   - 今日行动开关默认开，但没数据时渲染一张写着「暂无安排」的空卡，长期占位。
   - 首次运行（无账户无流水）时 `isFirstRun` 直接把整页替换成记账引导，健康/待办的引导完全没有。
6. **没有个性化**。设置页只有 3 个开关（今日行动 / 隐藏金额 / 健康提示），不能调顺序、不能选显示哪些、不能选每个块显示多少。
7. **单点故障影响整页**。`_HomeDashboard` 只要 5 个记账 provider 里任意一个 `hasError`，整页变 `AppErrorState`；健康/待办数据坏了也会一起白屏。
8. **页面在变长**。三合一卡省过一次高度，但分类 + 最近流水 + 两个小卡仍在首屏下方堆叠，手机要滚很久才看到待办/健康。

## 二、设计目标

把首页从「记账 App 的首页」升级成「本地生活 App 的首页」，一句话：

> **一眼看到「钱 / 健康 / 行动」三个维度的今天，并能原地完成最常见的下一步动作。**

设计原则：

- **P1 三维并列**。钱、健康、行动三者的「今天」在首屏同级出现，任何单一模块都不再独占。
- **P2 状态 + 定量 + 动作**。每个模块块都回答三件事：现在处于什么状态（状态）、关键数字是多少（定量）、我能点哪里（动作）。只有「有没有」的展示一律视为不合格。
- **P3 可插拔、可排序**。每个区块是一个独立注册的 Block，设置页可开关与拖拽排序，默认值开箱即用。
- **P4 统一提醒**。跨模块的待处理事项汇到一处，带来源图标，一次看完。
- **P5 空态一致**。未启用某模块时给出「启用引导」而非空白；未记录时给出可直接补记的入口。
- **P6 故障隔离**。任一模块数据失败只影响该块，不再整页白屏。
- **P7 不跳动**。沿用既有「条件区块出现/消失不引起页面跳动」的约束。

## 三、信息架构

从「一条长列表」改为「三层结构 + 可插拔区块」：

```
┌─ L0 身份层（固定） ───────────────────────────────┐
│  问候 + 日期                              👁 隐藏金额 │
│  状态胶囊：🔥连续 7 天 · 🩺经期第 3 天 · ✅ 2/5      │
└──────────────────────────────────────────────────┘

┌─ L1 今日层（固定核心） ────────────────────────────┐
│  今日三宫格                                         │
│  ┌────────┐ ┌────────┐ ┌────────┐                  │
│  │ 💰 今日 │ │ 🩺 健康 │ │ ✅ 行动 │                  │
│  │ 支出   │ │ 第 3 天 │ │ 2 / 5  │                  │
│  └────────┘ └────────┘ └────────┘                  │
└──────────────────────────────────────────────────┘

┌─ L2 模块层（可插拔 · 可排序） ─────────────────────┐
│  [统一提醒]  [记账区]  [健康区]  [行动区]           │
└──────────────────────────────────────────────────┘

┌─ L3 洞察层 ───────────────────────────────────────┐
│  跨模块洞察 + 语录                                  │
└──────────────────────────────────────────────────┘
```

**响应式**：手机单列；平板 / 桌面 ≥840dp 走 8/4 双栏。每个 Block 声明尺寸提示 `sm / md / lg`：`sm` 两两并排，`md/lg` 占满栏宽。双栏时按声明顺序交错填充两栏（不必人工指定左右）。

### 3.1 布局模式：纵向单列 / 横向分页（设置里选）

首页提供两种布局，设置页可切换（`homeLayoutMode`）：

| 模式 | 形态 | 说明 |
| --- | --- | --- |
| **纵向单列** | 一块块往下滚 | 沿用上面的 L0–L3 结构；平板上 8/4 双栏 |
| **横向分页**（默认） | 顶部四页，左右滑动 | 页 = `概览 / 记账 / 健康 / 行动`；Block 按 `module` 归页，页内顺序仍遵循全局顺序 |

横向分页的规则：

- **默认不显示顶部标签**（`homePagerTabs = false`）。用**左右滑动 + 底部圆点**切换，首屏给一行 `‹ 左右滑动查看 记账 · 健康 · 行动 ›` 提示；圆点可点。
- 若想更明确，可在设置里打开「分页显示顶部标签」，则渲染 `概览 / 记账 / 健康 / 行动` 分段标签。
- 概览页 = 三宫格 + 接下来（今日待办摘要，最多 3 条）+ 统一提醒 + 跨模块洞察 + 语录；其余页只放该模块的 Block。
- 某模块的所有 Block 都关掉时，对应页显示「该模块暂无显示内容 → 到设置里打开」。
- **与底部导航的分工**：首页分页是「今日摘要」，底部导航进的是完整模块页，两者不互相替代；若担心同名歧义，可把分页标签命名为「今日记账 / 今日健康 / 今日行动」。

两种模式共享同一份 `HomeBlockLayout`（可见性 + 顺序），切换模式不丢配置。

## 四、Block 清单（注册表）

新增一层 `HomeBlock` 抽象：每个 Block 有 `id / 模块 / 尺寸 / 默认可见性 / 依赖数据 / 空态策略`。设置页与布局都基于这张表。

| id | 名称 | 模块 | 尺寸 | 默认 | 依赖 | 空态策略 |
| --- | --- | --- | --- | --- | --- | --- |
| `today.board` | 今日三宫格 | 全局 | lg | 开（**可在设置逐格关闭**） | 钱+健康+行动 | 各格独立降级为 `—` |
| `reminders.unified` | 统一提醒 | 全局 | lg | 开 | 四类提醒 | 无内容整体不渲染 |
| `money.hero` | 预算 / 趋势 / 日历 | 记账 | lg | 开 | 记账一堆 | 记账首启引导 |
| `money.categories` | 分类结构 | 记账 | lg | 开 | 分类聚合 | 引导记一笔 |
| `money.recent` | 最近流水 | 记账 | lg | 开 | 流水 | 引导记一笔 |
| `health.cycle` | 周期状态 | 健康 | lg | 开（随健康总开关，默认开） | 健康快照 | 未开启追踪→启用引导 |
| `health.today` | 今日健康记录 | 健康 | lg | 开（随健康总开关，默认开） | 每日日志 | 全未记录→快捷补记 |
| `health.forecast` | 未来 7 天预测 | 健康 | lg | 关 | 周期预测 | 数据不足→隐藏 |
| `action.todo` | 今日待办 | 待办 | lg | 开 | `todayActionItemsProvider` | 无待办→引导新建 |
| `action.habit` | 习惯打卡 | 打卡 | md | 开 | `todayProgressProvider` | 无计划→引导新建 |
| `insight.cross` | 跨模块洞察 | 全局 | lg | 开 | 各模块洞察 | 无洞察→隐藏 |
| `footer.quote` | 语录 | — | lg | 开 | 静态 | 永远显示 |

> 决策补充：**健康总开关默认「开」**（未开启经期追踪时显示引导卡而非消失）；`today.board` **常驻、但允许逐格关闭**（至少保留 2 格，只留 2 格时两格撑满）。

> 说明：`health.*` 三块在**未开启经期追踪**时合并为一张「开启健康追踪」引导卡，避免三块各自显示空态。

## 五、各区块详细设计

### 5.1 L0 状态胶囊

一行小胶囊，最多 3 个，按可用性动态出现：

- `🔥 连续记账 7 天`（已有 `homeStreakProvider`）
- `🩺 经期第 3 天` / `距下次 12 天` / `孕期第 20 周`（`homeHealthHintProvider` 复用）
- `✅ 今日 2/5`（`todayActionItemsProvider`）

点击任一胶囊直达对应模块。**不必新查库**——这三个数据首页本来就在取。

### 5.2 L1 今日三宫格（`today.board`）

首页的新主心骨：三个等宽格子，每格「图标 + 标签 + 主数字 + 副文案」，整格可点。**默认常驻，设置页可逐格关闭**（至少保留 2 格；只留 2 格时两格撑满宽度）。

| 格 | 主数字 | 副文案 | 点击去向 |
| --- | --- | --- | --- |
| 💰 今日 | 今日支出 `¥51.17` | 本月还可花 `¥413` | 记一笔 / 流水 |
| 🩺 健康 | `经期第 3 天` | `今天已记录 4 项` / `今天还没记录` | 健康今日 |
| ✅ 行动 | `2 / 5` | `下一件 · 交房租` / `全部完成 🎉` | GTD 今日 |

- 无预算时「钱格」主数字退化为今日支出，副文案退化为本月结余（沿用 hero 的自适应逻辑）。
- 金额受全局「隐藏金额」开关约束。
- 三格任意一格数据缺失时显示占位 `—`，不隐藏整块——保证三列结构稳定、不跳动。

### 5.3 记账区

保持现有效果，只做两处收敛：

- `money.hero` 仍是三视图合一卡（预算 / 趋势 / 日历），不动。
- `money.categories` 与 `money.recent` 改为**默认折叠**为「一行摘要 + 展开」：
  - 分类：`餐饮 63% · 交通 12% · 更多` → 点击展开完整结构。
  - 流水：`最近 1 小时前 · 星巴克 ¥32` → 点击进流水页。
  - 这样手机首屏能腾出约 240dp 给健康/行动区。

### 5.4 健康区

**`health.cycle`（周期状态）** — 替换现在的一行窄条，用现有 `currentUserHealthTodaySnapshotProvider`：

- 左侧环形进度：`当前周期第 N 天 / 平均周期 L 天`，环内文案为阶段名。
  - 阶段由 `HealthCyclePrediction` 的 `nextPeriodStart / fertileWindow* / pms*` 推导：经期 / 卵泡期 / 排卵期 / 黄体期 / PMS。
- 右侧三行：
  - 距下次经期 `12 天`（或 `经期已推迟 2 天`；孕期显示 `第 20 周 · 距预产期 140 天`）
  - 预测窗口：`预计 10/24 – 10/28`
  - `去记录` 按钮
- 未开启经期追踪：显示「开启经期追踪 →」引导，不显示空环。

**`health.today`（今日健康记录）** — 一行 4 个可点小项，复用 `HealthDailyLog`：

| 项 | 已记录 | 未记录 |
| --- | --- | --- |
| 心情 | emoji + 文案 | `+` |
| 睡眠 | `7h20m` | `+` |
| 饮水 | `1200ml` | `+` |
| 体重 | `52.4kg` | `+` |

点任意项直接拉起对应的快速记录弹窗（复用 `health_quick_dialogs.dart`），**不跳页**。

**`health.forecast`（未来 7 天预测）** — 默认关，进阶用户可开：

- 一条 7 天色带：经期（红）/ 易孕（绿）/ PMS（黄）/ 普通（灰）。
- 依据 `HealthCyclePrediction` 的窗口日期落在未来 7 天的交集。

### 5.5 行动区

**`action.todo`（今日待办）** — 现有小卡升级为**可勾选列表**，直接读 `todayActionItemsProvider`。首页支持**完成 / 新增 / 删除 / 编辑**全操作，尽量不跳页：

- 顶部：`今日 2/5` + 进度环 + `连续打卡 7 天`。
- 列表取前 3–5 条，按现有 `_compareActionItems` 排序（逾期优先 → 优先级 → 未完成 → 时间）：
  - 逾期条目：红色左边框 + `逾期 2 天` 标签。
  - 优先级：左侧小圆点（高红 / 中橙 / 低蓝）。
  - **完成**：点复选框直接完成，完成后淡出、不跳页，并给可撤销 Toast。
  - **删除 / 编辑**：条目右滑或长按出菜单，走既有仓储的软删 / 编辑；删除同样给可撤销 Toast。
- **新增**：卡片底部 `+ 添加待办`，拉起既有快速创建 sheet（`todo_quick_create_sheet.dart`）。
- 底部 `查看全部 →` 进 GTD。
- 无待办时：`今天没有待办` + `+ 添加` 按钮，而不是空卡占位。

**`action.habit`（习惯打卡）** — 横向可滑的打卡项，读 `todayProgressProvider`（`PlanProgress`）：

- 每项：图标（`plan.icon`）+ 名称 + 进度（`currentValue/targetValue`）+ 一键打卡按钮。
- 已完成项显示 `✓` 并对勾；`streak` 有值时显示 `🔥N`。
- 无计划时与 `action.todo` 合并为「今日无安排 + 新建任务 / 新建习惯」。

### 5.6 统一提醒（`reminders.unified`）

> 状态：**已实现**（M2）。

扩展现有 `HomeAlertsStrip`，把四类事件合并成一条带来源图标的列表，最多 3 条 + `全部`：

| 来源 | 图标 | 数据 |
| --- | --- | --- |
| 记账 | 💳 | `currentUserPendingReminderCenterItemsProvider` |
| 待办 | ✅ | 逾期 / 今天到期的 `allTodoTasksProvider` |
| 打卡 | 🔥 | `reminderEnabled` 且今天未完成的计划 |
| 健康 | 🩺 | 经期/排卵/PMS 提醒（`HealthPeriodSettingsModel` + 预测窗口） |

- 排序：逾期 > 今天到期 > 3 天内 > 普通（复用记账提醒的 `priority` 思路）。
- 无内容时整块不渲染（保持现状）。
- 每行点右侧动作直接处理（记账记账、待办完成、打卡打卡、健康去记录）。

### 5.7 跨模块洞察（`insight.cross`）

在现有 `homeInsightProvider`（纯记账洞察）之外补跨模块条目：

- 行动：`本周完成率 82%，比上周 +6%`（`todoStatsSummaryProvider`）。
- 健康：`本周睡眠平均 6h40m，比上周少 20 分钟`（`currentUserHealthTrendSummaryProvider.healthMetrics`）。
- 关联（Phase 4 再做）：`睡眠 < 6h 的次日支出平均高 22%`。

每条带可点目标，沿用现有 `HomeInsightSegment / target` 结构。

## 六、设置与个性化

设置页「首页显示」一节从 3 个开关扩成两组：

**A. 模块开关与排序**（新）

- **布局**：纵向单列 / 横向分页（`homeLayoutMode`）；横向时可选「分页显示顶部标签」（`homePagerTabs`，默认关）。
- 按模块分组列出全部 Block，每组一个总开关 + 组内单项开关（如「健康」组下 周期 / 今日记录 / 预测；「今日三宫格」下 钱 / 健康 / 行动 逐格）。
- **支持拖拽排序**（`ReorderableListView`），顺序持久化。
- 每块可配置项（展开）：
  - 今日待办：显示条数（3 / 5 / 全部）、是否允许首页直接编辑。
  - 健康今日记录：显示哪些指标（心情 / 睡眠 / 饮水 / 体重，多选）。
  - 统一提醒：最大条数（2 / 3 / 5）。

**B. 既有开关**（保留）

- 隐藏金额、健康提示（重命名为「健康区块」，语义扩展）。

**存储**：`user_preferences` 表新增四列 `home_block_visibility`（JSON，`{blockId: bool}`）、`home_block_order`（JSON 字符串数组）、`home_layout_mode`（文本，默认 `pager`，可选 `list`）、`home_pager_tabs`（布尔，默认 `false`）。走既有 `drift_preferences_repository` 的更新方法，补一次 drift 迁移。旧用户读不到时回落到默认注册表 / 默认布局。

## 七、数据层改动

**新增聚合 provider（`lib/features/home/application/`）**

| provider | 组合来源 | 用途 |
| --- | --- | --- |
| `homeTodayBoardProvider` | `homeTodaySpendingSummary` + `homeHealthHint` + `todayActionItems` | 三宫格 |
| `homeHealthBriefProvider` | `currentUserHealthTodaySnapshot`（推导阶段）+ `currentUserHealthTrendSummary` | 健康区 |
| `homeActionBriefProvider` | `todayActionItems` + `todayProgress` + `checkinStreak` + `todoStatsSummary` | 行动区 |
| `homeUnifiedRemindersProvider` | 记账提醒 + `allTodoTasks` + 计划提醒 + 健康预测窗口 | 统一提醒 |
| `homeCrossInsightProvider` | `homeInsight` + `todoStats` + `healthTrend` | 跨模块洞察 |

**复用**：健康记录写入、待办完成、习惯打卡全部复用现有 repository / controller，不新写业务逻辑。

**容错**：三宫格与各 Block 各自 `AsyncValue` 渲染，`hasError` 只让该块显示重试，不再触发整页 `AppErrorState`。

**性能**：`_HomeDataPreloader` 按「首屏块 → 次屏块」分批预取；新块的数据大多可从已取的 provider 派生，不额外打库。
