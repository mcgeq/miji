问题定位（P0）

  • 1浮层是 Stack 子节点，不占页面流，必然盖住内容。
  • 2被盖的正好是首行最右那 1~3 个控件（流水「筛选」、账户「新建」、统计动作组…）。
  • 3浮层在 Stack 里排在内容之后 → 命中测试先给它，不是看不全，是点不到。
  • 48 个面板里 7 个中招；仅「分类」因整排收起（hidePrimaryNav）幸免。

方案要点

  • A入口搬到底部导航「记账」（已在模块内再点才弹选择器）＋ 宽屏放工具行 chip；内容区零导航 UI。
  • B只做「去浮层」：导航回到页面流，压成 32px chip 行（+36px，不遮挡、一拍切换）。
  • C路由不必拆成 path 二级路由：?section= 已经是可寻址的二级视图，拆 path 会丢面板保活。

待确认

  • 1底栏「记账」是否接受两态（不在模块内直接进 / 已在模块内弹选择器）。
  • 2宽屏入口用工具行 chip，还是宽屏继续留浮层（右上角多为空白，伤害小）。
  • 3选 A（省满 77px）还是 B（常驻 36px、一拍切换）。
