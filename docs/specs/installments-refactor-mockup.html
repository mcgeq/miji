问题定位（P0）

  • 1数值格写死单行省略：_InstallmentSummaryMetric 用 maxLines:1 + ellipsis，装不下就截断，不换行、不缩字号。
  • 2「下一期」的值是复合长串：_nextDueText() 产出 2026-10-03 · 已逾期（≈16 字符），却塞进一格短指标里。
  • 3宽屏用固定像素宽度：非紧凑布局是 Wrap + 写死 132 / 132 / 132 / 132 / 96，既放不下长串，尾行两个格还右对齐参差。
  • 4紧凑布局同病：手机上是 2 列 Expanded，每格约 150px，2026-10-03 · 已逾期 依旧溢出。

重构清单

  • P0把「下一期」从指标格提升为到期条：独立一行，左「日期 + 第 N 期」，右「还剩 N 天」chip；主次分离，永不截断。
  • P0缩短日期文案：当年省略年份（10月20日），跨年才带年；相对时间压成 还剩 3 天。
  • P0指标格改等宽自适应网格：auto-fit + minmax(92px, 1fr) 取代固定 132px，金额仍走 MoneyText 并可自适应缩字。
  • P1到期条内联「去入账」：现在入账只能进明细弹窗（卡片只有「查看明细」）。
  • P1搜索框上提到页头：分期是唯一把搜索放在面板内容里的面板，与流水/预算/分类/自动记账不一致。
  • P1逾期优先：有逾期时顶部出一条汇总条（2 期逾期 · 共 ¥2,400），一键跳第一条逾期。
  • P2状态筛选：进行中 / 已结束 / 已取消 分段，取代只靠「已结束」折叠。

落地说明（P0 + P1 已实现）

  • ✓到期条、短日期、等宽指标网格、搜索上提、逾期汇总条均已落地。
  • !逾期条改为纯信息：原设计右侧的「去处理」要靠 GlobalKey + ensureVisible 滚到那笔逾期，实测在懒加载列表里会触发 !childSemantics.renderObject._needsLayout 断言，故去掉按钮，改为一句可读的结论（卡片上的「已逾期 N 天」仍然高亮）。
  • !无待入账时文案：终态计划默认收起金额，所以到期条只在「已跳过 / 无待入账」时出现，文案定为 暂无待入账期次 而非「已全部入账」（后者由状态胶囊表达）。
  • +另加了一条卡片内「去入账」路径（到期条右下角按钮），仍在设计内。
