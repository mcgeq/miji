Miji · Period Redesign

经期功能改版评审

对 lib/features/health/ 现有实现的逐块诊断，以及「今日 / 日历 / 趋势 / 设置」四个面板的重构方案。所有改版都基于现有 HealthRepository / Provider，不新增数据层；标 数据 的项目属于必须修复的功能缺陷。下方可切换明暗主题，每个标注元素都可点击查看说明。

现状诊断：13 个具体问题

逐文件核对 presentation/ 与 health_page.dart。前 4 条是功能缺陷，不是审美问题。

  1. 1
    编辑每日记录会清空已有数据数据health_page.dart 的 onEditDailyLog 固定传 HealthDailyLog.empty(selectedDay)，即使当天已有记录也打开空表单；保存时 symptoms / exerciseIntensity / diet / calories / medications 全部取空值回写，等于删除。今天点「更多」就会触发。
  2. 2
    「更多」既打开表单又派发一次空动作数据_CalendarQuickChip.onPressed 先调 onEditDailyLog()，再调 onQuickAction(more)；more 分支是 break，但整套 _handleCalendarQuickAction 仍会先构造 existing 快照，逻辑绕且脆弱。
  3. 3
    预计经期推迟时文案出错数据healthPredictionCycleDayLabel 直接拼 daysUntil：经期推迟 3 天会显示「预计 -3 天后开始经期」。HealthPredictionService 没有 overdue 分支。
  4. 4
    隐藏设置被静默回写数据dataSyncEnabled / analyticsEnabled 在 UI 中完全不存在，却每次 _autoSave 都随 draft 写回，用户无法感知也没法修改。
  5. 5
    日历格子只有 3 个 6px 圆点体验经期 / 预计 / 经前 / 易孕 4 种状态共用同一种视觉（markerBuilder 取前 3 个画点），用户分不清哪天是「已发生」哪天是「预测」。
  6. 6
    两套颜色体系打架主题格子底色用硬编码 Color(0xFFE57373) 等 7 个颜色（_phaseColor），标记点又用 markerColor(colorScheme)；深色 / 暖色主题下这 7 个硬编码色对比度不合格，且和 App 主色系脱节。
  7. 7
    快捷动作是一团 25px 的药丸主题8 个 _CalendarQuickChip 字号 11、高约 25px、间距 6，触控目标远低于 48dp；「更多」和「结束经期」混在同一排，无主次。
  8. 8
    只有选中「今天」才有上下文_TodayPredictionPanel 仅当 isTodaySelected 时渲染，选中其它日期时顶部完全空白，看不到周期第几天、下次经期。
  9. 9
    同一段摘要逻辑复制两份体验_SelectedDayPanel._buildSummary 与 health_today_tab.dart._DailySummary 几乎逐行相同；而 HealthTodayTab 主页面根本没用到（只有 dev mock 用）。
  10. 10
    趋势页没有结论、没有基准体验折线图不显示数值、无平均线；「周期对比」只有两个平均数，不给样本量、不给波动范围；分布图用 LinearProgressIndicator，只有「x 天」没有占比。
  11. 11
    筛选器要用户自己选日期体验5 个 ChoiceChip + 一个日期选择器，没有「近 3 周期 / 近 6 月 / 近 1 年」这类快捷区间；interval: 1 让 x 轴标签在数据点多时必然重叠。
  12. 12
    设置只有 +/- 没有输入体验周期 18–45 共 28 档只能连点；每次点按即时落库，没有保存反馈、没有撤销；提醒三个开关没有任何「什么时候响、响什么」的预览。
  13. 13
    孕期模式是个残废入口体验开始只取「今天」，不能改开始日期、不能填预产期——而 HealthPregnancyDraft 明明有 startDate 和 dueDate。结束孕期用裸 AlertDialog，和其它面板的 AppDialogScaffold 风格不一致。

改版目标

四条原则，全部服务于「一眼知道现在处于什么阶段 + 一步记完当天」

Hero周期状态先行任何面板顶部都有一张周期 Hero：第几天、什么阶段、还有几天来月经，不再要求用户先选中「今天」。
Encoded格子会说话经期实心、预测量虚线描边、易孕/经前只做浅色底，颜色语义化并全部走主题 token；图例常驻。
Touch记录是大按钮把 8 个 25px 药丸换成 4×2 的 48dp+ 磁贴，已记录的显示绿点，点一下即改，不再有「更多」这种模糊入口。
Insight趋势要给结论先给一句人能懂的话（规律 / 波动 / 异常），再给图和表；图表带平均线与数值，分布给占比。

记录表（统一编辑器）HealthDailyLogSheet + 6 个 dialog 合并8 处重复构造 HealthDailyLogDraft 收敛为 1 处。
提醒时间预览reminderDays + 三个 *ReminderEnabled + 新增「提醒时间」偏好新偏好仅影响通知调度与展示文案。
孕期开始/结束HealthPregnancyDraft.startDate / dueDate、HealthPregnancyEndDraft字段已存在，补日期选择器与预产期输入即可。
数据与隐私dataSyncEnabled / analyticsEnabled修复从「隐藏回写」改为显式开关。

实现前的修复清单（按优先级）

这些是改版落地时必须一起处理的，否则新 UI 只是把旧 bug 换个皮肤。

优先级位置动作
P0health_page.dart onEditDailyLog改用 currentUserHealthDailyLogProvider(selectedDay) 回填真实记录；或直接在日历选中日面板内联编辑，不再弹空表单。
P0health_action_dialogs.dart ×6抽出 HealthDailyLogDraft.copyWith，把 6 处「整份复制」改成字段级合并，从根上避免丢字段。
P0health_prediction_service.dart增加 isOverdue/daysOverdue，文案分「还有 N 天 / 今天开始 / 已推迟 N 天」三分支。
P1health_text.dart删除或显式暴露 dataSyncEnabled / analyticsEnabled；给 healthPredictionBasisLabel（已存在未用）接到 Hero。
P1health_calendar_tab.dart删除 _phaseColor 硬编码，统一走主题扩展；_groupMarkers 的 key 改为 HealthDate.dayKey。
P1health_today_tab.dart要么挂到主页面（改版方案正是如此），要么删除，避免第二份摘要逻辑漂移。
P2drift_health_repository.dartStream.fromFuture 是伪响应式，靠 _refreshAfterWrite 手动失效。改版不要求重构，但应记录为技术债。
