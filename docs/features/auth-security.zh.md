# 认证与安全

> English: [auth-security.md](auth-security.md) · [← 返回功能指南](README.zh.md)

米记**没有服务端、也没有账号找回** —— 一切都是本地的。因此安全分三层：本地账号、可选的应用锁，以及针对最敏感页面的短时解锁。

## 本地账号

用户用 用户名 / 邮箱 + 密码 注册。密码从不以明文存储：用 **PBKDF2** 哈希，凭据放进加密存储（`flutter_secure_storage`），而不是明文数据库。

米记支持**同一设备上的多个本地用户**。绝大多数状态（偏好、逐账户隐藏设置、缓存）都按 userId 隔离，所以切换用户不会把一个人的设置或数据漏进另一个人的会话。

## 应用锁

可选的应用锁在你离开应用后保护它。两种方式：

| 方式 | 说明 |
| --- | --- |
| **PIN** | 6 位数字 |
| **手势图案** | 安卓风格的连线图案 |

锁会校验密钥形状（位数、图案长度、重复/非法节点），也可以关闭。锁定时会话保留，但界面被挡在解锁页后面。

## 敏感数据二次验证

即使在已解锁的应用里，最敏感的两个模块 —— **记账**与**健康** —— 也可以要求二次验证后才渲染。验证通过后，解锁在可配置的 **TTL** 内有效：

`10 分钟`（默认）· `1 小时` · `3 小时` · `12 小时` · `30 天` · `90 天` · `永久`

这让一台共用或临时递出去的设备不会因随手一瞥就暴露财务或健康数据，同时也不必每点一下就输一次密码。
