# 打卡与待办（GTD）

> English: [gtd.md](gtd.md) · [← 返回功能指南](README.zh.md)

这个模块把两类「要做的事」放到一起：**习惯打卡**（可重复、可配照片 / 计时 / 目标的计划）和**任务**（带状态、优先级、日期的一次性待办）。一个共享的外壳给它们统一的日历与统计。

进入模块默认落在**今日**，有五个面板：

| 面板 | 作用 |
| --- | --- |
| **今日** | 混排的行动流：今天的任务与习惯打卡放在一起 |
| **任务** | 完整任务列表，含分类、标签、筛选与重复规则 |
| **习惯** | 打卡计划及其进度 / 连续天数 |
| **日历** | 任务与打卡合并的月视图 |
| **统计** | 任务完成趋势与汇总 |

## 打卡

### 计划（`CheckinPlan`）

一个计划就是你想定期做的事。它带：

- **名称、图标、颜色、分类**（健康习惯 / 学习成长 / 运动 / 生活记录 / 纪念日 / 其他）。
- **计划类型**：循环（持续重复）或事件（一次性场合）。
- **频率**：每天 / 每周 / 每月 / cron / 一次，可带配置。
- **目标**：一个数值与单位（如「8 杯」「30 分钟」）。
- **触发方式**：按钮 / 照片 / 计时 / 位置 —— 决定一次打卡怎么确认。
- **记录粒度**：合并（一天一条）或明细（多条）。
- **可见性**（针对记录）与可选的**提醒**（时间 + 提前天数）。
- **目标值 / 单位**、**归档**标记与手动**排序**。

每个计划都带一份按类型区分的「附加数据」：饮水、排便、学习、运动、照片、纪念日或通用。

### 记录（`CheckinRecord`）

一次具体打卡，挂在某个计划上。记录累积出**连续天数**与相对目标的**进度**。照片打卡会存下图片。

### 计时

配了计时触发的计划用「运行中 / 暂停」的计时状态，于是「运动 30 分钟」是被计量出来的，而不是估的。

## 待办

### 任务（`TodoTask`）

任务有标题、**状态**、**优先级**、可选的**计划日期**、**分类**、**标签**，以及可选的**重复规则**。

- **快速创建** —— 只填标题的面板（全局快速新增按钮也用它），默认排到今天。
- **详情页** —— 完整编辑、重复规则与元信息。
- **列表** —— 搜索、按状态/日期筛选、分组。
- **统计** —— 近 7 天 / 30 天 / 本月的完成趋势。

## 主要流程

### 你的一天

**今日**面板把今天的任务与习惯打卡交错排在一起，一屏回答「还剩什么没做」。完成打卡或任务后它会从列表消失；已完成的收在一个可折叠区块里。

### 管理计划

**习惯**面板列出计划及其进度。计划可以新建、编辑、归档或查看（含历史记录）。
