# 打卡与待办（GTD）

> English: [gtd.md](gtd.md) · [← 返回功能指南](README.zh.md)

这个模块把两类「要做的事」放到一起：**习惯打卡**（可重复、可配照片 / 计时 / 目标的计划）和**任务**（带状态、优先级、日期的一次性待办）。一个共享的外壳给它们统一的日历与统计。

进入模块默认落在**今日**，有五个面板：

| 面板 | 作用 |
| --- | --- |
| **今日** | 按一天的时间轴分段的行动流：先给结论，再给清单 |
| **任务** | 完整任务列表，含分类、标签、筛选与重复规则 |
| **习惯** | 打卡计划及其进度 / 连续天数 |
| **日历** | 任务与打卡合并的月视图 |
| **统计** | 任务完成趋势与汇总 |

## 打卡

### 计划（`CheckinPlan`）

一个计划就是你想定期做的事。它带：

- **名称、图标、颜色、分类**（健康习惯 / 学习成长 / 运动 / 生活记录 / 纪念日 / 其他）。
- **计划类型**：循环（持续重复）或事件（一次性场合）。
- **频率**：每天 / 每周 / 每月 / cron / 一次，可带配置。
- **目标**：一个数值与单位（如「8 杯」「30 分钟」）。
- **触发方式**：按钮 / 照片 / 计时 / 位置 —— 决定一次打卡怎么确认。
- **记录粒度**：合并（一天一条）或明细（多条）。
- **可见性**（针对记录）与可选的**提醒**（时间 + 提前天数）。
- **目标值 / 单位**、**归档**标记与手动**排序**。

每个计划都带一份按类型区分的「附加数据」：饮水、排便、学习、运动、照片、纪念日或通用。

### 记录（`CheckinRecord`）

一次具体打卡，挂在某个计划上。记录累积出**连续天数**与相对目标的**进度**。照片打卡会存下图片。

### 计时

配了计时触发的计划用「运行中 / 暂停」的计时状态，于是「运动 30 分钟」是被计量出来的，而不是估的。

## 待办

### 任务（`TodoTask`）

任务有标题、**状态**、**优先级**、可选的**计划日期**、**分类**、**标签**，以及可选的**重复规则**。

- **快速创建** —— 只填标题的面板（全局快速新增按钮也用它），默认排到今天。
- **详情页** —— 完整编辑、重复规则与元信息。
- **列表** —— 搜索、按状态/日期筛选、分组。
- **统计** —— 近 7 天 / 30 天 / 本月的完成趋势。

## 主要流程

### 你的一天

**今日**面板按一天的时间轴组织，自上而下是：

1. **结论区** —— 一个进度环，环里是**今天还剩几件**（不是完成百分比），右边一句「最紧：交房租 · 逾期 2 天」直接指出第一条该做的事。
2. **常驻添加** —— 顶部一行输入框，输完回车就落到今天。以前这一屏**加不了任务**（工具栏只有「新建计划」），得先切到「任务」面板。
3. **分段清单** —— 顺序固定为 `逾期 → 随时 → 上午 → 下午 → 晚上 → 今日打卡 → 已完成`：

   | 段 | 收什么 |
   | --- | --- |
   | 逾期 | 过了期还没做完的，永远置顶；段标题右侧有一键「全部改到今天」 |
   | 随时 | 没有截止时间的任务。刻意排在有时间的任务之前：先清掉无约束的杂事 |
   | 上午 / 下午 / 晚上 | 有 `dueAt` 的按小时归组（06–12 / 12–18 / 18–06，深夜并入晚上） |
   | 今日打卡 | 习惯计划单独成段 —— 它的完成方式是计数 / 计时 / 拍照，与勾选不同 |
   | 已完成 | 默认折叠，勾完不把列表顶下来；展开后打卡行仍可撤销一次 |

4. **全做完 / 空态** —— 全做完时环变绿并预告明天；今天没安排时给两个出口：「新建任务」与「从待安排挑」（把收集箱里没排期的任务拉进今天）。

行内的操作：**右滑完成**、**左滑改期 / 删除**、**长按进入多选**（底部批量条可批量完成或改到今天）。勾选圈的命中区是 44×44，视觉仍是 24px。

### 管理计划

**习惯**面板列出计划及其进度。计划可以新建、编辑、归档或查看（含历史记录）。
