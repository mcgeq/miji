# 记账

> English: [bookkeeping.md](bookkeeping.md) · [← 返回功能指南](README.zh.md)

记账是米记里最大的模块：它同时管**钱在哪**（账户）、**发生了什么**（流水）、**要花去哪**（预算）和**长什么样**（统计），以及让这几件事保持一致的一整套机制（分期、自动记账、提醒）。

进入模块默认落在**流水**页。整个模块分为五个面板：

| 面板 | 作用 |
| --- | --- |
| **流水** | 完整流水列表，含搜索、类型/状态/日期/标签筛选、批量操作与回收站 |
| **账户** | 账户列表，按 资产 / 信用负债 / 停用 分组，附净资产 |
| **预算** | 周期、作用域、分配与预警 |
| **统计** | 22 张图表与卡片组成的分页看板 |
| **更多** | 分类、分期、自动记账、提醒 |

## 核心概念

### 账本（`MoneyLedger`）

所有数据都属于某个账本。分两种：

- **个人账本** —— 每个用户自动创建。
- **家庭账本** —— 成员共享（用于分摊）。

账本选择器在顶栏（窄屏）或页面工具行上。每笔流水都记录它所属的账本。

### 账户（`MoneyAccount`）

账户就是钱所在的地方。类型包括现金、银行卡、支付宝、微信、花呗、白条、信用卡、贷款、投资，以及一个系统内部账户。账户带币种、初始余额、当前余额，以及可选的信用信息（额度、账单日、还款日、账单周期起始日）。

- **资产类**：余额就是你有多少钱。
- **信用 / 负债类**：信用是可用额度，贷款是剩余欠款（正数）。
- **停用**：退出日常视野，但保留历史。

卡面按**语义组**渲染，不按 16 个类型逐个设计：可花余额（现金 / 银行 / 储蓄 / 钱包）、预付余额、授信额度、负债、持仓。每组一套固定骨架 —— 图标与名称 → 主值 → 右侧辅助值 → 进度条（授信看额度使用率、负债看已还比例）→ 底部动作行。组间差异只落在文案与那一条进度上，卡片高度因此可控。贷款账户早年掉进资产分支，显示过「当前余额 −¥486,200 / 初始 −¥600,000」，现在按负债渲染：剩余欠款 + 已还进度 + 本金（建账时录入）。

余额不直接编辑。要让账面和现实一致，走**余额对账**（见下）。

**点账户卡、或点卡底的「查看流水」图标**（只有图标，靠 tooltip 与语义标签说明用途——卡底已经有一行对象级入口文字，再挤一个文字按钮会把账户名挤成省略号），打开的是同一个账户弹窗（概览 + 可筛选流水），不再切走面板。弹窗概览与卡面共用同一份月度合计（自然月、已完成、排除转账），所以文案里明确标注「不含转账」——列表按账户筛选时**包含**转账的两条记录（转出 / 转入各一条）。批量改分类、跨账户搜索仍然只有老的流水面板能做，出口保留为弹窗底部的次要**图标**按钮（`list_alt`，「在流水中查看全部」）；弹窗里唯一的写操作「记一笔」同样是图标（`add`，填充态）。两个都靠 tooltip 与语义标签说明用途，与卡底「查看流水」同一口径——文字按钮在 320dp 上会换行，而它们只是对象级入口，不是这一屏的主任务。

**时间范围会进 provider 的 family key，所以必须归一到「天」。** 「近 90 天」原来直接用 `DateTime.now()` 减 90 天，毫秒每帧都不同 → key 每帧都变 → provider 被反复销毁重建，列表永远停在 loading。现在统一取当天零点；「本期」用账单区间时同样归一。

**遮罩停在弹窗外面。** 「隐藏金额」是全局偏好，账户卡还能按账户单独显隐（显式显示 > 显式隐藏 > 全局）。这个状态只作用于**卡面**：账户弹窗是用户主动点开的详情页，里面一律展示真实金额，从弹窗再点开的流水详情也一样。理由有两条 —— 弹窗里没有眼睛开关，遮住之后用户没有第二个入口把它打开；而「点开还是 ••••、又点不动」会被直接当成坏了。实现上作用域（`MoneyPrivacyScope`）仍挂在 `ProviderScope` 正下方而不是 Shell 里：对话框走根导航器，挂 Shell 里读不到，只会退回「不遮」的兜底值。

### 流水（`MoneyTransaction`）

一笔流水有三种类型：

- **支出 / 收入** —— 带分类，（支出）带支付方式。
- **转账** —— 在两个账户之间搬钱，不带分类。

流水还有状态：**已完成**、**待处理**（记了但不占余额、不进统计）、**已作废**。每笔可带名称、备注、商家、地点、标签和退款金额。删除会进**回收站**（保留 30 天）。

### 分类（`MoneyCategory` / `MoneySubCategory`）

两级：一级分类 + 子分类，各带名称、颜色、图标。有内置种子分类，也可自建。分类可以「停用」而不是删除。

### 标签

流水可带标签。**支出的标签是单标签**（一个标签字符串），这样「按标签的预算」才不含糊。候选来自历史流水与已有预算标签，选而不是手输。

### 预算（`MoneyBudget`）

预算把「花多少 / 赚多少」和「追踪方式」组合起来：

- **周期**：每天 / 每周 / 每月 / 账单周期 / 每年 / 一次性（固定起止日期）；
- **作用域**：全部 / 按分类 / 按账户 / 分类+账户 / 按标签；
- **追踪类型**：支出限额或收入目标；
- 可选的**分配**（把预算分摊到子分类或成员）与**自动结转**剩余额度。

预算卡展示执行进度、节奏提示（花得比时间快/慢）、临近阈值的预警，以及已被自动记账 / 分期**预留**的额度。

### 分期计划（`MoneyInstallmentPlan`）

分期会冻结信用账户的本金，并按期生成一笔支出。每期有状态（待入账 / 已入账 / 已还清），并关联到生成的流水。

### 自动记账模板（`MoneyAutoPostingTemplate`）

模板按计划定时生成流水（例如每月 1 号的房租）。若同一笔还款被分期和模板重复登记，模板可以被分期**接管**（停用），米记会把冲突标出来。

### 账单提醒（`MoneyBillReminder`）

信用卡还款等周期性账单的提醒。完成提醒可以落一笔流水；提醒中心把全部到期事项汇总在一起。

### 分摊（`MoneySplit`）

家庭账本下，一笔支出可按 等额 / 固定金额 / 比例 / 权重 / 自定义 规则在成员之间分摊。

## 主要流程

### 记一笔

表单字段顺序按真实填写习惯排：**金额 → 分类 → 支付方式 → 账户 → 日期 → 名称 → 备注 → 状态 → 更多 → 分摊**。账户和支付方式互相锁定（选了信用卡账户会锁到对应方式），「他人代付」会切到系统内部账户。列表里还支持「保存并继续」，连记多笔。

### 余额对账

账户的**对账 / 校正**入口让你把账面余额和实际余额对比：按账期（本月 / 上月 / 近 3 月）摊开 `期初余额 + 期内收入 − 期内支出 = 应有余额`，输入实际余额后，差额通过**初始余额**补齐 —— 不产生流水，也不污染统计。

### 导入与导出

流水可导出为 CSV。Android 上可以把**小票 / 账单截图**做端侧识别（OCR），预填进记账表单。
