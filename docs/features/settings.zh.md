# 设置

> English: [settings.md](settings.md) · [← 返回功能指南](README.zh.md)

设置把「不是日常操作」的那些东西收在一起：你的账号、应用长什么样、各模块的默认值，以及数据怎么备份。

## 区块

| 区块 | 内容 |
| --- | --- |
| **账户与安全** | 账号资料（头像、用户名、邮箱）、修改密码、退出登录 |
| **外观与显示** | 主题模式（浅色 / 深色 / 跟随系统）、隐藏金额、健康提示 |
| **记账偏好** | 默认币种与记账模块基础参数（含提醒设置） |
| **数据与同步** | WebDAV、本机加密快照、增量同步诊断、旧数据导入 |
| **关于** | 版本与本地优先的数据说明 |

## 数据与同步

这是最重的一块，覆盖四件事：

- **WebDAV 配置** —— 指向一个 WebDAV 服务器、设置同步密码，并选择是否在启动时同步、是否自动增量同步。
- **本机加密快照** —— 创建、查看与恢复整个数据库的快照。恢复后需要重新登录。
- **增量同步诊断** —— 设备身份、待上传的本地变更、远端游标与冲突数量，用来判断同步是否健康。
- **旧数据导入** —— 一次性导入旧桌面版的记账数据。

同步是**可选且加密的**：除非你配置了目标并主动触发，否则数据不会离开设备。

## 隐私开关

- **隐藏金额**会把应用里所有金额遮住。单个金额仍可从账户菜单里临时显示（逐账户），而**收入金额默认独立遮罩**（见[记账指南](bookkeeping.zh.md)）。
- **健康提示**控制首页那条细细的周期窄条是否显示。
