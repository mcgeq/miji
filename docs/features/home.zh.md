# 首页

> English: [home.md](home.md) · [← 返回功能指南](README.zh.md)

首页是「钱 / 健康 / 行动」三维并列的生活仪表盘。它的任务是**一眼回答「我最近怎么样」**，并在尽量少的点击内把你送进常用操作。

## 布局

- **横向分页（默认）**：四页 `概览 / 记账 / 健康 / 行动`，左右滑动切换，底部圆点指示当前位置。顶部标签默认关闭，可在设置里打开。
  - **循环滑动**：滑到「行动」再往前滑会绕回「概览」，在「概览」往回滑则到「行动」，两端没有断点。点页签跳页走最短路径（概览 → 行动是往回退一格，不是横穿三页）。
- **纵向单列**：一块块往下滚；平板与桌面 ≥840dp 走 8/4 双栏。
- 在「设置 → 首页显示 → 布局」里切换，两种布局共享同一份区块配置。

## 区块

| 区块 | 展示内容 |
| --- | --- |
| **问候头** | 按时段变化的问候语、日期与金额隐私开关 |
| **状态胶囊** | 问候语下方一行最多 3 颗：🔥 连续记账天数（今天还没记账时改成提醒）、🩸/🤰 健康状态一句话、✅ 今日完成度；点哪颗进哪个模块。横竖两种布局都固定在顶部 |
| **今日三宫格** | 钱 / 健康 / 计划三格同级。每格统一四层：模块名 → 主值 → 主值口径 → 次要指标，主次一眼可分。可逐格关闭（至少留 2 格） |
| **接下来 · 今日待办** | 概览页最多 3 条待办，可直接勾选；点「查看全部」进 GTD |
| **统一提醒** | 记账 / 待办 / 打卡 / 健康 四类待处理事项汇到一处，按紧急度排序（逾期 → 今天 → 3 天内 → 普通），每行可直接处理 |
| **记账 · 预算 Hero** | 本月预算 / 支出趋势 / 日历三视图合一卡 |
| **记账 · 分类结构** | 默认折叠为一行摘要，点开看完整分类占比 |
| **记账 · 最近账单** | 默认折叠为最近一笔摘要，点开看完整列表 |
| **健康 · 周期状态** | 周期环 + 当前阶段 + 距下次经期 / 推迟 / 孕期周数；未开启追踪时是启用引导 |
| **健康 · 今日记录** | 心情 / 睡眠 / 饮水 / 体重，点任意项原地补记 |
| **健康 · 未来 7 天** | 默认关。一条 7 天色带：经期 / 易孕 / PMS / 普通 |
| **行动 · 今日待办** | 可直接勾选完成、添加、编辑、删除；逾期与优先级有标记 |
| **行动 · 习惯打卡** | 进度 + 一键打卡 + 连续天数 |
| **净资产** | 资产 - 负债 |
| **洞察条** | 跨模块观察：钱（「比上期多花 18%」）、行动（「本周完成率 82%」）、健康（「最近睡眠平均 6h40m」），每条可点击跳转 |
| **首启引导** | 还没有数据时展示的记账 / 健康 / 行动三模块向导 |

## 行为说明

- 状态胶囊是「速览层」：只给结论（`经期第 3 天`），三宫格给口径与明细。三颗胶囊与三宫格同源同数据，不额外查库；任一颗没数据就整颗不渲染，三颗都没有时整行消失。
  - 连续记账那颗写「连续记账」而不是「连续」——行动模块的习惯打卡也有「连续 N 天」，两颗同时出现时只说「连续」会分不清在说哪一件。
- 三宫格每一格都是「模块名 → 主值 → 主值口径 → 次要指标」四层；主值与次要指标之间有一条极淡的分隔线，避免把两个口径混读。
  - 钱格：**有预算**时主值是本月还可花，**没有预算**时退化为本月结余；超支时主值转为告警色并把口径改成「本月已超支」。今日支出永远是带名称的次要指标。
  - 健康格：主值只用短文本（`第 3 天` / `5 天` / `—`），完整句子留给口径标签与说明，避免窄格子里被截断。
  - 计划格：主值是完成度 `2 / 5`，「下一件」降为次要指标。
  - 缺数据的那一格只显示 `—`，不隐藏整块。
- 健康三块在**未开启经期追踪**时收敛成一张「开启健康追踪」引导卡。
- 所有金额跟随全局「隐藏金额」开关；收入金额默认遮罩（点一下收入金额即可临时显示，详见记账指南）。
- 布局刻意保证「条件区块出现/消失不引起页面跳动」：空态与有数据时占位一致。
