# 首页

> English: [home.md](home.md) · [← 返回功能指南](README.zh.md)

首页是两个数据模块之间落地的那块仪表盘。它的任务是**一眼回答「我最近怎么样」**，并用尽量少的点击把你送进常用操作。

布局是响应式的：手机上**单列**，平板与桌面用 **8/4 双栏**。

## 区块

| 区块 | 展示内容 |
| --- | --- |
| **问候头** | 按时段变化的问候语与月份选择 |
| **余额 hero** | 主角数字 —— 有预算时是「本月还可花」，没有预算时退化为本月结余 —— 外加「时间 vs 花费」进度条与明细（已用 / 日均可花 / 收入） |
| **提醒条** | 需要立刻处理的（账单到期、预算预警） |
| **洞察条** | 一句话观察（「比上期多花 18%」「花得比时间快」） |
| **概览卡** | 本月 收 / 支 / 结余 |
| **周趋势** | 近期支出的小柱状图 |
| **分类结构** | 钱花在哪，按一级与子分类 |
| **支出日历** | 热力图式的月历，点某天可补记一笔 |
| **最近流水** | 最新动态，可点进详情 |
| **健康窄条** | 当前周期状态的一瞥 |
| **指标磁贴** | 一组紧凑的次级指标 |
| **快捷操作** | 进入最常用录入流程的捷径 |
| **首启引导** | 还没有任何数据时展示的引导视图 |

## 行为说明

- 主角数字会自适应：**有预算**时显示本月还能花多少（把「已预留」算进去），**没有预算**时退化为本月结余。
- 所有金额都跟随全局「隐藏金额」开关；**收入金额默认遮罩**（点一下收入金额即可临时显示，详见记账指南）。
- 布局刻意保证「条件区块出现/消失不引起页面跳动」：空态与有数据时占位一致。
