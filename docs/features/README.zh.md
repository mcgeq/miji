# 功能指南

> English: [README.md](README.md) · [← 返回项目总览](../../README-zh.md)

米记分为五个模块，位于底部导航，另有一层横切的认证与安全。每篇指南说明**这个模块做什么**、它的**核心概念与数据模型**、以及**主要流程** —— 讲行为，不讲实现。想知道某个设计决策背后的「为什么」，顺着每篇底部的链接进 `docs/` 里的计划与审查文档。

| 指南 | 模块 | 一句话 |
| --- | --- | --- |
| [记账](bookkeeping.zh.md) | 📒 记账 | 账户、收支转账、预算、统计、分期、自动记账、账单提醒、分摊与账本 |
| [健康](health.zh.md) | 🩺 健康 | 经期记录与预测，以及完整的每日健康日志 |
| [打卡与待办](gtd.zh.md) | ✅ 打卡与待办 | 习惯打卡与任务管理，共用一套日历与统计 |
| [首页](home.zh.md) | 🏠 首页 | 两个数据模块之间那块「一眼看懂」的仪表盘 |
| [设置](settings.zh.md) | ⚙️ 设置 | 账户与安全、外观、各模块偏好、WebDAV 同步与旧数据导入 |
| [认证与安全](auth-security.zh.md) | 🔐 认证与安全 | 本地登录、应用锁与敏感页二次验证 |

## 约定

- 每篇指南有两个文件：`<name>.md`（英文）与 `<name>.zh.md`（中文），顶部可互相切换。
- 指南讲的是「应用做了什么」。需求、路线图与设计审查放在上一级的 [`docs/`](../) 里，由每篇指南的页脚链过去。
