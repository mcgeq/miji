# 健康

> English: [health.md](health.md) · [← 返回功能指南](README.zh.md)

健康模块记录经期与每日身心状态，并据此预测后续节奏。它是一本**周期手账**，不是医疗设备 —— 所有预测都是基于历史记录与设置的估算。

进入模块默认落在**今日**，有四个 tab：

| Tab | 作用 |
| --- | --- |
| **今日** | 当前周期状态、当日记录，以及快速填写入口 |
| **日历** | 月视图，标注 经期 / 易孕 / PMS / 有记录的日子，点开看单日详情 |
| **趋势** | 周期长度与经期长度趋势，以及按阶段筛选的记录 |
| **设置** | 周期参数、提醒、数据选项 |

## 核心概念

### 经期记录（`HealthPeriodRecord`）

一次经期 = 开始日期 + 可选结束日期 + 可选备注。相邻两次开始之间的间隔是**周期长度**，一次「开始 → 结束」是**经期长度**。

### 周期设置（`HealthSettings`）

用户可控制：

- **平均周期长度**与**平均经期长度**（在历史数据足够之前先用它兜底）。
- 经期 / 排卵 / PMS **提醒**，以及提前多少天提醒。
- 数据选项（同步 / 分析）。

### 预测（`HealthPrediction`）

结合设置与历史，米记估算**下次经期起止**、**易孕期**、**PMS 窗口**，并给出当前**周期第几天 / 经期第几天**。每个预测都记录它的**依据**（设置 / 历史 / 怀孕），界面因此能说清楚「为什么这么算」。

### 怀孕记录（`HealthPregnancyRecord`）

怀孕记录有开始日期、预产期与状态（进行中 / 已完成 / 流产 / 终止）。处于进行中时，周期预测切换为怀孕模式，追踪**当前孕周**。

### 每日记录（`HealthDailyRecord`）

每天一条，覆盖：

- **流量等级**（点滴 / 少 / 中 / 多）
- **症状** —— 单独一张列表，每条含类型与强度
- **情绪**（开心 / 难过 / 生气 / 焦虑 / 平静 / 易怒）
- **运动强度**、**性生活**、**避孕方式**
- **体征与习惯** —— 饮食、饮水、睡眠、体重、体温、压力、卡路里
- 自由**备注**

同一份数据既可以从「今日」填，也可以在「日历」里点某一天填。

## 主要流程

### 记录今天

「今日」页顶部是当前状态横幅，下面是当天的快捷录入（流量、情绪、症状、饮水……一步直达）。完整表单面板则暴露全部字段。

### 看日历

月视图标出经期 / 易孕 / PMS 日，以及任何有记录的日子。点某一天打开详情，在那里新增或修改记录。

### 看趋势

「趋势」页把周期长度、经期长度随时间画出来，并支持按阶段（经期 / PMS / 易孕 / 非经期）筛选记录，于是「症状是不是总在经期前冒出来」这类规律就看得见了。
