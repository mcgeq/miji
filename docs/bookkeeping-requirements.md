## 1. 文档说明

### 1.1 目的

本文档完整描述记账模块已实现的功能、业务规则、数据结构、状态流转、交互流程与边界条件，作为开发、测试、验收的统一依据。

### 1.2 范围

覆盖账户、流水、分类、预算、分期、自动记账、账单提醒与提醒中心、统计与分析、分摊、账本与成员、快捷记账，以及相关的通知与多设备行为。

不覆盖：登录与解锁流程、首页自身布局、健康与待办模块。

### 1.3 术语

| 术语 | 含义 |
| --- | --- |
| 账本 | 记账数据的隔离维度，分个人账本与家庭账本。 |
| 账户 | 资金载体，分资产型、信用/负债型、内部虚拟账户。 |
| 流水 | 一笔收入、支出或转账；转账由成对的两条流水表示。 |
| 有效金额 | 原金额扣除已登记退款后的金额，用于余额、预算与统计。 |
| 主导币种 | 统计区间内出现次数最多的币种；统计只按该币种汇总。 |
| 快照 | 周期结束时冻结的预算/分配执行结果，用于历史趋势。 |
| 提醒中心 | 聚合账单、预算、分期等到期事项的统一待办入口。 |
| 内部账户 | 系统为「他人代付」等场景准备的辅助账户，不计入资产与统计。 |
| 重算版本号 | 记录每次修改的版本，用于同步冲突判断与变更追踪。 |

### 1.4 需求书写与验收约定

- **FR（功能需求）**：用户可观察的能力，应可验证；验收以「用户可观察到的结果」为准。
- **BR（业务规则）**：必须总是成立的约束与计算口径，不因界面变化而改变。
- **NFR（非功能需求）**：性能、离线、安全、体验等约束。
- 关键流程的预期结果见[附录 26](#26-附录关键用户流程)；字段限制见[附录 24](#24-附录字段校验与取值范围)；异常表现见[附录 25](#25-附录边界与异常场景)。

### 1.5 范围边界（不在范围内）

以下内容不属于本模块需求：
- 登录、注册、解锁与应用锁的具体流程（仅要求记账数据受其保护）；
- 首页自身的布局与视觉设计（仅描述其读取的记账数据与联动）；
- 健康、待办等其它业务模块；
- 数据导入/导出（当前未实现）；
- 多币种汇率换算（见[3.1](#31-金额与币种)）。

### 1.6 假设与依赖

- 每个用户至少拥有一个可用账本（默认个人账本）；
- 记账数据按登录用户隔离；
- 消息通知依赖系统通知权限，未授权时功能仍可用、仅不推送；
- 使用习惯排序依赖历史数据，数据不足时回退到原始顺序；
- 「他人代付」等场景依赖系统内部账户。

### 1.7 用户与角色

| 角色 | 说明 |
| --- | --- |
| 记账用户 | 记账模块的主要操作主体，拥有自己的账本与数据。 |
| 家庭账本成员 | 参与分摊的成员，角色分「成员」「管理员」，用于成员管理与分摊统计。 |
| 系统 | 自动记账、到期入账、提醒扫描、快照采集、统计与报表等后台行为。 |

## 2. 模块总览

### 2.1 功能地图

记账模块由「4 个常驻面板 + 更多面板」组成：

| 面板 | 功能 |
| --- | --- |
| 流水 | 收入/支出/转账的记录、查看、筛选、编辑、退款 |
| 账户 | 资产与负债账户概览、信用卡账单、净资产 |
| 预算 | 支出限额/收入目标、额度分配、执行历史 |
| 统计 | 收支分析、趋势、来源、额度、报表 |
| 分类 | 支出/收入分类与子分类的增删改、排序、颜色图标 |
| 分期 | 分期计划与每期入账 |
| 自动记账 | 定时自动生成流水 |
| 提醒 | 账单提醒与提醒中心 |
| 更多 | 二级面板入口，含待处理提醒数量角标 |

**FR-2.1.1** 面板切换后，系统返回操作应回到上一个面板，而不是退出记账模块。

**FR-2.1.2** 已访问过的面板在切换时保持原有状态（筛选、滚动位置），不重新加载。

**FR-2.1.3** 首屏优先呈现必要数据，其余面板按需加载。

**FR-2.1.4** 当前账本切换入口在页面顶部（窄屏时收纳进弹层）。

### 2.2 领域关系

```
账本 ── 账户 ── 流水 ── 分类 / 标签 / 分摊
  │        │       ├── 分期计划 ── 分期明细
  │        │       └── 自动记账 ── 执行记录
  ├── 成员
  ├── 预算 ── 预算分配 ── 预算快照
  ├── 账单提醒
  └── 分析报表
```

## 3. 通用业务规则

### 3.1 金额与币种

- **BR-3.1.1** 所有金额以「分」为最小单位（整数）存储，`1 元 = 100`，字段命名以 `_minor` 结尾；避免浮点误差。
- **BR-3.1.2** 用户输入解析到分：去除千分位、空白，四舍五入到整数分；空输入视为 0；非法输入按解析失败处理。
- **BR-3.1.3** 金额展示按币种选择区域格式与符号，固定保留两位小数。
- **BR-3.1.4** 模块支持币种：CNY（默认）、USD、EUR、JPY、HKD、GBP、AUD、CAD、SGD、KRW。
- **BR-3.1.5** 不维护汇率换算层，跨币种不折算；每条业务记录各自携带币种。
- **BR-3.1.6** 统计与资产汇总按「主导币种」计算；存在其它币种时置混合币种标记并在界面提示。

### 3.2 时间

- **BR-3.2.1** 流水发生时间以 UTC 存储，展示时转换为本地时间。
- **BR-3.2.2** 日历类日期（周期、到期日、快照周期等）以本地日历日为准，按 `YYYYMMDD` 整数键存储。
- **BR-3.2.3** 周期边界：日从当天 0 点起；周从周一起；月从当月 1 号 0 点起。区间语义为**含开始、不含结束**（`[start, endExclusive)`）。
- **BR-3.2.4** 涉及月份推进（分期、重复提醒）时使用日历加法，并按目标月天数收敛（如 1 月 31 日 + 1 月 = 2 月最后一天）。

### 3.3 软删除与恢复

- **BR-3.3.1** 账户、分类、流水、预算、提醒、分期、模板、账本均采用软删除：置 `is_deleted = true` 并记录 `deleted_at`，同时递增重算版本号。
- **BR-3.3.2** 软删除后历史数据保留，可恢复；恢复时清空删除标记、恢复启用状态。
- **BR-3.3.3** 账户提供回收站：可查看已删除账户并恢复。
- **BR-3.3.4** 分类管理页可查看已删除分类并恢复；已删除分类不出现在记账选择器中。

### 3.4 版本号与变更日志

- **BR-3.4.1** 所有可同步实体带 `version`（默认 1）与 `device_id`；每次写入递增 `version`。
- **BR-3.4.2** 本地写入时记录**变更日志**：实体、记录 ID、操作类型（新增/修改/删除）、变更字段、修改前版本、修改后版本。
- **BR-3.4.3** 变更日志用于多设备增量同步与冲突判断。
- **BR-3.4.4** 内置分类与子分类为设备共享数据，其**排序变更只写本地、不进入变更日志**；自建分类的排序进入变更日志并同步。

### 3.5 使用习惯记录

- **BR-3.5.1** 系统按用户记录账户、分类、子分类、支付方式、账户×支付方式的使用次数、累计金额与最近使用时间。
- **BR-3.5.2** 新增、修改、删除、退款流水后重建对应用户的使用记录。
- **BR-3.5.3** 账户与分类/支付方式的「常用」排序规则：**最近使用 → 使用次数 → 累计金额 → 原始顺序**。

### 3.6 金额显示

- **BR-3.6.1** 用户可开启「隐藏金额」；账户页另提供逐账户隐藏与「全部隐藏/显示」。
- **BR-3.6.2** 逐账户状态优先级：**显式显示 > 显式隐藏 > 全局隐藏**。
- **BR-3.6.3** 隐藏设置按登录用户分别保存，互不影响。

### 3.7 关键算法口径

**BR-3.7.1 预算自动结转**：仅对开启自动结转的循环预算生效。计算当前周期预算时，取该预算**上一个已结转周期快照的正剩余**作为结转额，叠加到本期预算金额；上一周期快照状态置为「已结转」。已结转周期的负剩余（超支）不冲减本期。

**BR-3.7.2 预算已用额**：只统计当前周期、属于预算账本、状态为已完成、类型与跟踪类型一致（支出限额看支出、收入目标看收入）、且命中作用域的交易有效金额；排除转账、转账分类与转入标记。标签作用域采用集合包含匹配。

**BR-3.7.3 预算分配已用额**：按分配的「分类」筛选预算周期内的交易；若分配绑定了成员，则取这些交易的有效分摊明细中该成员应承担的金额之和；未绑定成员则取交易有效金额之和。历史快照类预算直接使用已冻结的已用额。

**BR-3.7.4 信用卡账期**：账期起点由「预算周期起始日」（缺省取账单日）决定，按账单周期推进；应还日按配置的还款日生成；本期还款取账期内转入该信用账户的转账。

**BR-3.7.5 信用卡应还额**：
- 未出账：应还额取「已入账负债」与「本期消费」的较小值（两者均大于 0 时）；
- 已出账：应还额 = 已入账负债 + 本期消费 − 本期还款（不小于 0）；
- 账单来源优先级：已出账（应还 > 0）→ 未出账（有消费或应还）→ 当前欠款（已入账负债 > 0）→ 未出账。

**BR-3.7.6 资产快照**：每日对启用且非虚拟的账户采集一次余额快照；同一账户同一天已存在则不重复采集，「刷新」会覆盖当日快照。净资产趋势按日期聚合快照，资产与负债分别求和，并把「今天」的实时余额并入最新数据点（首次使用当天自动采集）。

**BR-3.7.7 使用统计**：统计每个账户/分类/子分类/支付方式/账户×支付方式的使用次数、累计金额与最近使用时间，作为「常用」排序依据。

**BR-3.7.8 统计分组推断**：自定义区间跨度不超过 93 天按日分组，否则按月分组；区间为「含开始、不含结束」。

### 3.8 并发与幂等

- **BR-3.8.1** 自动记账同一「模板 + 到期标识」只入账一次；并发执行时未抢到的实例直接跳过。
- **BR-3.8.2** 预算快照按「预算 + 周期 + 来源版本」唯一，重复刷新不会产生重复快照。
- **BR-3.8.3** 提醒中心事项按「来源 + 来源 ID + 到期日」唯一，重复扫描不会重复出现。
- **BR-3.8.4** 信用账户自动还款提醒按固定来源键幂等创建。
- **BR-3.8.5** 数据刷新事件在同一事件循环内合并，避免重复刷新风暴。

### 3.9 删除后的历史展示

- **BR-3.9.1** 删除账户后，其历史流水仍保留；详情中该账户显示为「账户已不可用」。
- **BR-3.9.2** 删除分类/子分类后，其历史流水仍保留；详情中显示为「分类已不可用」。
- **BR-3.9.3** 删除预算不影响已产生的流水。
- **BR-3.9.4** 删除自动记账模板不影响已生成的流水。
- **BR-3.9.5** 删除账本/成员后，历史分摊记录不再展示为有效记录，但流水保留。

## 4. 账户管理

### 4.1 目标

管理全部资金账户，维护余额与信用额度，并以净资产视角呈现资产与负债。

### 4.2 账户类型

| 类型 | 取值 | 资产型 | 信用型 | 负债型 | 钱包型 | 内部 |
| --- | --- | --- | --- | --- | --- | --- |
| 现金 | `cash` | ✓ | | | | |
| 银行账户 | `bank` | ✓ | | | | |
| 信用卡 | `credit_card` | | ✓ | ✓ | | |
| 花呗 | `huabei` | | ✓ | ✓ | | |
| 白条 | `baitiao` | | ✓ | ✓ | | |
| 美团月付 | `meituan_credit` | | ✓ | ✓ | | |
| 其他信用账户 | `other_credit` | | ✓ | ✓ | | |
| 储蓄账户 | `saving` | ✓ | | | | |
| 投资账户 | `investment` | ✓ | | | | |
| 贷款账户 | `loan` | | | ✓ | | |
| 支付宝 | `alipay` | ✓ | | | ✓ | |
| 微信 | `wechat` | ✓ | | | ✓ | |
| 云闪付 | `cloud_quick_pass` | ✓ | | | ✓ | |
| 预付卡 | `prepaid_card` | ✓ | | | | |
| 其他 | `other` | ✓ | | | | |
| 内部账户 | `internal` | | | | | ✓ |

- **BR-4.2.1** 未知类型回退为 `cash`。
- **BR-4.2.2** 信用型账户用于分期、「他人代付」等场景；`loan` 属于负债型但不是信用型。

### 4.3 账户字段

**FR-4.3.1** 账户字段：`id`、所属用户、名称、说明、类型、账面余额、初始余额、信用额度、已入账负债、冻结额度、账单日、预算周期起始日、还款日、自动还款提醒开关、币种、是否共享、是否虚拟、所属成员、颜色、图标、是否启用、软删除标记、删除时间、版本号、创建/更新时间。

**FR-4.3.2** 信用型账户额度与债务：
- 信用额度默认取初始余额；
- 已用额度 = 已入账负债 + 冻结额度；
- 可用额度 = 信用额度 − 已用额度；
- 信用型账户对外展示「可用额度」，其它账户展示「账面余额」。

#### 余额计算规则

- **BR-4.3.3** 资产型账户：收入 `+金额`、支出 `−金额`；转账流入 `+金额`、流出 `−金额`。
- **BR-4.3.4** 信用型账户：支出使已入账负债 `+金额`、收入使负债 `−金额`；转账流入使负债 `−金额`；任何变化后按「可用额度」刷新账面余额。
- **BR-4.3.5** 校验：资产型账户账面余额不得为负；信用型账户已用额度不得超过额度；初始余额不得为负。
- **BR-4.3.6** 内部虚拟账户跳过余额校验。
- **BR-4.3.7** 编辑账户时：
  - 非信用账户调整初始余额，按差额平移账面余额；
  - 非信用 → 信用：清空历史负债与冻结；
  - 信用 → 非信用：账面余额重置为初始余额，清空额度/负债/冻结；
  - 信用 → 信用：保留负债与冻结，额度取新初始余额。

**FR-4.3.8** 账户表单字段与交互：
- 通用字段：账户名称、账户类型、备注、账户颜色；
- 信用型账户额外显示：账单日、预算周期起始日、还款日；
- 信用型账户显示「自动还款提醒」开关，说明为「根据还款日每月提醒，欠款为 0 时不弹系统通知」。

### 4.4 账户列表

**FR-4.4.1** 净资产概览：净资产 = 资产余额合计 − 信用/负债已用额度合计；展示总资产、总负债与占比条。仅统计启用账户，排除内部账户，使用账本基准币种。

**FR-4.4.2** 账户按分组展示；选中「信用/负债」分组时展示本期应还、可用额度、逾期/待还笔数汇总。

**FR-4.4.3** 支持按状态（全部/启用/停用）、类型、币种筛选。

**FR-4.4.4** 支持按更新时间、创建时间、名称、余额、类型排序，可切换升降序；默认按更新时间倒序。

**FR-4.4.5** 列表分页加载（每页 8 个），滚动加载更多；下拉刷新同时刷新月度汇总与账户数据。

**FR-4.4.6** 账户卡片展示图标、名称、类型、说明、余额或可用额度、信用额度进度条、本月收入/支出与环比。

**FR-4.4.7** 账户操作：编辑、启用/停用、删除、查看该账户流水、显示/隐藏金额、更多操作。

**FR-4.4.8** 账户回收站：入口展示已删除账户数量；弹层列出已删除账户并可恢复，说明「已删除账户的历史流水不会丢失，恢复后账户重新可用」。

**FR-4.4.9** 账户删除为软删除（同时停用），不影响历史流水与统计历史。

### 4.5 账户与账本

**FR-4.5.1** 个人账本可见全部未删除、非虚拟账户。

**FR-4.5.2** 家庭账本只可见已加入该账本的账户；支持把账户加入/移出家庭账本。

**FR-4.5.3** 家庭账本下的转账可选择系统内部账户。

### 4.6 内部辅助账户

**FR-4.6.1** 系统为每个用户维护唯一内部虚拟账户（用于「他人代付」等场景）。

**FR-4.6.2** 内部账户不出现在账户列表、总资产、统计与预算账户范围中，仅在记账弹窗中可选。

### 4.7 信用卡账单

**FR-4.7.1** 系统为信用型账户计算当前账单，来源分三种：
1. **已出账**：已到账单日且生成账单；
2. **当前欠款**：无账单周期时的负债视图；
3. **未出账**：账单周期内尚未出账。

**FR-4.7.2** 账单字段：账户、币种、来源、账期起止、还款日、本期消费、本期还款、本期应还、可用额度、已入账负债、状态、待对账项、账期流水。

**FR-4.7.3** 账单状态：未出账、待还款、临近还款、已逾期、已还清。

**FR-4.7.4** 提供信用卡对账弹层「账单核对」，展示账单头部、各项金额、差额、待对账项与账期流水。

**FR-4.7.5** 账单核对提供两个动作：
- **还款**：打开转账表单，预填转入账户为该信用账户、金额为本期应还、备注「信用卡还款」，提交后记录一笔还款转账；
- **补记差额**：当「本期消费 − 本期还款 − 本期应还 > 0」时显示，按差额生成一笔支出流水（描述「信用账单差额补记」，备注「账单核对自动补记，不计入收支统计」，归入系统转账分类，实际付款标记为转出），使账单对齐；
- **待核对项**：展示账单中的待对账记录。

**FR-4.7.6** 差额 = 本期消费 − 本期还款 − 本期应还（仅取正值）。

### 4.8 信用账户自动还款提醒

- **BR-4.8.1** 当信用账户启用、开启自动还款提醒并设置还款日时，自动创建还款提醒。
- **BR-4.8.2** 仅在已出账、应还金额大于 0 时创建；金额取账户当期负债，到期日为还款日，提前 1 天提醒，按月重复；以固定来源键保证幂等。
- **BR-4.8.3** 账户停用、删除、关闭提醒或不再有应还金额时，自动提醒被移除。
- **BR-4.8.4** 流水、账户、分期、自动记账变化后自动重算关联还款提醒。

## 5. 流水记录

### 5.1 目标

记录收入、支出、转账，并联动账户余额、预算、分期、分摊、统计与提醒。

### 5.2 流水类型与状态

| 类型 | 取值 | 说明 |
| --- | --- | --- |
| 收入 | `income` | 增加资产账户余额 |
| 支出 | `expense` | 减少资产账户余额或增加信用负债 |
| 转账 | `transfer` | 账户之间转移，成对记录 |

| 状态 | 取值 | 说明 |
| --- | --- | --- |
| 已完成 | `completed` | 参与余额与统计的正式流水 |
| 待处理 | `pending` | 不占用账户余额，不计入统计；确认后才入账 |
| 已作废 | `voided` | 不计入统计；由已完成作废时回滚余额 |

**FR-5.2.1** 新建收入/支出时可选状态（已完成 / 待处理，默认已完成）；转账固定为已完成。

**FR-5.2.2** 仅在流水详情提供状态动作：待处理可「确认入账」，已完成可「作废」。

**BR-5.2.3** 允许的状态流转：待处理 → 已完成（入账）、待处理 → 已作废（不入账）、已完成 → 已作废（回滚余额）；已作废不可再变更。

**BR-5.2.4** 余额与预算、统计均只计入已完成流水；编辑/删除待处理或已作废流水不影响余额。

### 5.3 流水字段

**FR-5.3.1** 必填：类型、金额（大于 0）、发生时间、账户、分类、支付方式。

**FR-5.3.2** 选填：子分类、描述、备注、商家、地点、标签、自定义支付方式名称、所属账本。

**FR-5.3.3** 其它系统字段：退款金额、目标账户（转账）、实际付款标记、关联流水（转账对）、来源执行记录（自动记账/分期）、利率与利息（分期）、版本号、软删除标记、创建/更新时间。

**FR-5.3.4** 记账表单支持：切换支出/收入、选择家庭账本归属、金额、账户、分类与子分类、支付方式、商家、地点、备注、标签。

**FR-5.3.5** 提供「保存并继续」，方便连续记账。

**FR-5.3.6** 表单记住上一次使用的账户、分类、子分类与支付方式，按「用户 + 账本 + 类型」分别记忆并回填。

**FR-5.3.7** 表单扩展能力：
- **转为分期支付**：录入支出且非编辑状态时，可一键转为分期计划，自动带入当前金额、账户、分类、子分类与名称；创建成功后关闭记账表单。入口说明为「转为分期计划，首期到期自动入账」。
- **内联分摊**：当选择家庭账本时，可在记账表单内直接设置分摊（「设置支出分摊」/「清除分摊」），提交时与流水一并创建；金额变化会清除旧分摊配置。
- **家庭账本归属**：可选择加入某个家庭账本，或选择「不加入家庭账本」。
- **输入建议**：商家、标签字段提供历史候选自动完成；标签仅支持单选（候选含历史标签与预算标签）。

### 5.4 支付方式

| 支付方式 | 取值 | 支付方式 | 取值 |
| --- | --- | --- | --- |
| 现金 | `cash` | 花呗 | `huabei` |
| 银行卡 | `bank_card` | 白条 | `baitiao` |
| 信用卡 | `credit_card` | 数字人民币 | `digital_rmb` |
| 支付宝 | `alipay` | 银行转账 | `bank_transfer` |
| 微信支付 | `wechat_pay` | 云闪付 | `union_pay` |
| 在线支付 | `online_payment` | 第三方 | `third_party` |
| 其他 | `other` | | |

- **BR-5.4.1** 未知支付方式回退为 `cash`。
- **BR-5.4.2** 选择「其他」时可填写自定义支付方式名称（如「美团月付」）。
- **BR-5.4.3** 自定义名称进入历史建议，供日后快速选择。

### 5.5 录入校验规则

- **BR-5.5.1** 支出必须选择支出分类，收入必须选择收入分类。
- **BR-5.5.2** 子分类必须属于所选分类且类型一致。
- **BR-5.5.3** 收入只能选择资产型且非负债的账户。
- **BR-5.5.4** 支出可选择资产型、信用型或内部账户。
- **BR-5.5.5** 转账必须走转账功能，不能通过普通收入/支出录入。

### 5.6 标签

- **FR-5.6.1** 支出流水支持标签，界面为单选（数据层保留多标签能力，界面只写入一条）。
- **FR-5.6.2** 标签候选 = 历史流水标签 ∪ 已有预算标签，去重并按最近使用排序。
- **BR-5.6.3** 标签用于「标签预算」匹配，采用完全一致匹配。

**FR-5.6.4** 提供「标签管理」入口（位于分类面板），列出历史交易标签与预算标签。

**FR-5.6.5** 标签重命名会**级联更新**所有引用该标签的流水与预算，保证关联不断；重命名到已存在标签时合并、不产生重复。

**FR-5.6.6** 标签删除会从所有流水与预算中移除该标签；历史流水保留。

### 5.7 输入建议

**FR-5.7.1** 从历史流水提炼常用商家（默认 8 条）与自定义支付方式名称（默认 6 条），用于自动完成与快捷选择。

### 5.8 流水生命周期

**FR-5.8.1** 新增流水后：更新账户余额/负债并校验、关联到账本、刷新受影响预算、重算信用还款提醒、更新使用记录。

**FR-5.8.2** 修改流水时先撤销旧影响再应用新影响，允许更换账户并同步迁移余额；退款金额自动收敛到新金额以内。

**FR-5.8.3** 删除流水时撤销余额影响、软删除并记录变更日志；若该流水来自自动记账，对应执行记录标记为「用户已删除」。

### 5.9 退款

- **FR-5.9.1** 仅「支出」且状态为「已完成」的流水可登记退款。
- **BR-5.9.2** 退款金额不小于 0 且不超过原金额。
- **BR-5.9.3** 有效金额 = 原金额 − 退款金额；余额、预算、统计均按有效金额计算。
- **BR-5.9.4** 退款增加时撤销账户影响，减少时反向补记。
- **BR-5.9.5** 分期入账、转账流水不允许退款。

**FR-5.9.6** 退款弹窗展示「原金额 / 已退款 / 剩余可退」，默认填入最大可退金额；校验金额大于 0 且不超过剩余可退。

### 5.10 转账

**FR-5.10.1** 转账记录为两条关联流水：一条转出、一条转入，金额、时间、币种、描述一致，并通过「关联流水」互相引用。

**FR-5.10.2** 转账描述默认「转账」；分类归入系统转账分类，可选支出子分类。

**FR-5.10.3** 转账修改会同步调整两条流水的账户影响；删除时成对删除。

**FR-5.10.4** 转账金额必须大于 0，转出与转入账户不能相同。

- **BR-5.10.5** 转出账户只能是资产型或内部账户。
- **BR-5.10.6** 转入账户可以是资产型、信用型或内部账户。
- **BR-5.10.7** 转账对完整性校验：类型均为转账、金额相等、互相关联、方向标记正确，否则视为非法。

### 5.11 流水列表与筛选

**FR-5.11.1** 列表按日分组，显示每日支出与收入小计；分页每页 20 条。

**FR-5.11.2** 筛选维度：类型（全部/支出/收入/转账）、预算、账户、账户类型、支付方式、自定义支付方式、分类、子分类、日期范围、关键词、商家。

**FR-5.11.3** 日期快捷区间：本周、本月、上月、近 90 天、自定义。

**FR-5.11.4** 支持按时间或金额排序，并切换升降序；次排序固定为创建时间以保证顺序稳定。

**FR-5.11.5** 顶部汇总条展示当前筛选条件下的**全量**笔数（含转账）、支出合计、收入合计（均扣除退款），不随分页变化。

**FR-5.11.6** 从统计、账户、预算跳转进入时带上对应筛选条件，并可一键清除；可锁定类型、账户、分类、日期范围。

**FR-5.11.7** 宽屏使用右侧详情面板，窄屏使用详情弹窗。

**FR-5.11.8** 关键词搜索覆盖描述、备注与商家。

**FR-5.11.9** 流水卡片支持左滑操作，并提供编辑、删除、退款入口。

**FR-5.11.10** 分期入账流水为只读，不可编辑、删除、退款，但可查看详情。

**FR-5.11.11** 无数据时展示空态与「记一笔」入口。

**FR-5.11.12** 删除流水前二次确认，提示「删除后会同步回滚账户余额」。

**FR-5.11.13** 对分期入账流水执行编辑/删除时提示「分期入账流水只能查看」。

**FR-5.11.14** 支持将当前筛选条件下的流水导出为 CSV（含时间、类型、金额、币种、账户、分类、子分类、支付方式、商家、地点、备注、标签、退款金额、状态），并调用系统分享；单次导出上限 5000 条。

### 5.12 流水详情

**FR-5.12.1** 详情展示金额、类型、账户、分类、支付方式、时间、商家、地点、备注、标签、账本归属、分期信息、分摊记录、退款信息。

**FR-5.12.2** 详情操作：编辑、删除、退款、设置/编辑/取消分摊、加入/移出家庭账本。

**FR-5.12.3** 详情分区：
- **核心信息**：账户（转账显示对方/目标账户）、分类、支付方式、币种；
- **备注**：备注、商家、地点、标签；
- **关联信息**：关联流水、分期计划；支出额外显示原金额、已退款、实际支出；
- **账本归属**：显示个人/家庭账本；未关联时提示「未关联个人账本」；家庭账本可移出（提示「此流水仍会保留在个人账本中」）；
- **分摊**：显示有效分摊（付款人、各成员金额/比例）；无分摊时可添加。

**FR-5.12.4** 转账详情显示方向（转入/转出）与带符号金额。

## 6. 分类管理

### 6.1 目标

维护支出与收入的一级分类和子分类，支持颜色、图标、排序、搜索、删除与恢复。

### 6.2 分类字段

**FR-6.2.1** 分类字段：名称、类型（支出/收入）、颜色、图标、是否内置、业务顺序、所属用户、软删除标记、版本号。

**FR-6.2.2** 子分类字段类似，另含所属父分类。

**FR-6.2.3** 唯一性约束（未删除时）：
- 内置分类：同一类型 + 名称唯一；
- 自建分类：同一用户 + 类型 + 名称唯一；
- 子分类在同一父分类下同理。

- **BR-6.2.4** 业务顺序为 0 表示未设置，排序时排最后。

### 6.3 分类管理页

**FR-6.3.1** 顶部分段切换支出/收入。

**FR-6.3.2** 支持搜索分类与子分类。

**FR-6.3.3** 提供常驻「新增分类」入口。

**FR-6.3.4** 每个分类可展开管理子分类，并展示本月金额、占比、使用次数与最近使用时间。

**FR-6.3.5** 分类与子分类支持新增、编辑、删除、恢复。

**FR-6.3.6** 排序模式：可拖拽调整顺序，顺序立即生效；支持恢复默认顺序。

- **BR-6.3.7** 内置分类也可重排，但重排只对当前设备生效、不进入同步；自定义分类的排序会同步。
- **BR-6.3.8** 删除后的分类不出现在记账表单选择器中，但可在管理页恢复。
- **BR-6.3.9** 管理页按用户设定顺序展示；记账时的分类选择器按「常用」浮动排序。

**FR-6.3.10** 点击子分类（chip）可直接进入「快速记一笔」，预填该分类与子分类且隐藏分类选择器，提交后提示「已记录」。

**FR-6.3.11** 子分类排序使用独立排序面板（避免与「点击快速记账」手势冲突），拖动调整并保存。

**FR-6.3.12** 删除分类在界面文案中表现为「停用分类」（停用后不出现在选择列表），恢复表现为「恢复分类」；管理页提供「已停用 N 个」折叠区，停用项不参与拖拽排序。

### 6.4 分类选择器

**FR-6.4.1** 记账表单通过分类选择器选择分类与子分类。

**FR-6.4.2** 选择器提供常用/全部切换、搜索、颜色图标展示。

**FR-6.4.3** 选择器可展示分类「本月花了多少」，与统计口径一致。

## 7. 预算管理

### 7.1 目标

按周期设定支出限额或收入目标，跟踪已用额度，支持额度分配、执行历史与超支提醒。

### 7.2 预算属性

| 属性 | 取值 |
| --- | --- |
| 跟踪类型 | `expense_limit`（支出限额）、`income_target`（收入目标） |
| 周期类型 | `daily`、`weekly`、`monthly`、`billing_cycle`、`yearly`、`one_time` |
| 作用域 | `all`、`category`、`account`、`category_account`、`tag` |
| 重复间隔 | 周期的整数倍（≥ 1） |

**FR-7.2.1** 预算字段：名称、说明、金额、币种、周期与重复间隔、作用域及分类/子分类/账户/标签、提醒开关与阈值、颜色、自动结转、启用状态、所属账本、创建成员、优先级、已用金额、当前周期起止与重置时间、版本号。

### 7.3 周期计算

- **BR-7.3.1** 每天：当天整天。
- **BR-7.3.2** 每周：本周一至周日。
- **BR-7.3.3** 每月：当月 1 号至下月 1 号。
- **BR-7.3.4** 账单周期：以所选账户的「预算周期起始日」为起点的一个账单月；未指定账户时不允许使用该周期。
- **BR-7.3.5** 每年：当年自然年。
- **BR-7.3.6** 一次性：必须指定开始与结束日期（含首尾当天），结束不能早于开始。
- **BR-7.3.7** 自动结转只对循环周期有效，一次性预算不适用。

### 7.4 已用额度与进度

**FR-7.4.1** 已用额度 = 当前周期内命中预算作用域的支出有效金额之和。

**FR-7.4.2** 作用域匹配规则：
- 全部：所有支出；
- 按分类：命中指定分类（可选子分类）；
- 按账户：命中指定账户；
- 分类+账户：分类与账户同时命中；
- 按标签：流水标签与预算标签一致。

- **BR-7.4.3** 标签预算是叠加关系（不互斥）：命中标签预算的支出同时计入其它预算。
- **BR-7.4.4** 收入目标按收入累计，达到金额即为完成。
- **BR-7.4.5** 支出限额在已用超过金额时标记为超支。
- **BR-7.4.6** 开启提醒并设置阈值后，已用比例达到阈值即触发提醒。

### 7.5 预算历史

**FR-7.5.1** 系统按周期记录预算执行快照：所属预算、账本、跟踪类型、周期与间隔、周期起止、预算金额、已用、剩余、币种、状态（进行中/已关闭/已结转）、冻结时间、来源版本号。

**FR-7.5.2** 预算分配同样按周期生成执行快照。

**FR-7.5.3** 唯一性约束：同一预算、同一周期、同一来源版本只保留一份快照。

**FR-7.5.4** 提供预算历史趋势（默认近 6 个月）：预算总额、已用、预算数、超支预算数、使用率。

**FR-7.5.5** 统计页提供「预算执行」卡片与「预算历史趋势」卡片。

**FR-7.5.6** 预算历史弹层按周期倒序展示快照，每条含预算金额、已用、剩余、状态；启用自动结转的预算显示「含结转」与「结转下期」；并展示该周期的分配快照（已停用分配标记为「已停用」）。

### 7.6 预算分配

**FR-7.6.1** 预算可拆分为多个分配项，按分类或成员分配。

**FR-7.6.2** 分配字段：所属预算、分类、成员、分配金额、已用、剩余、比例、分配方式（默认 `fixed`）、规则配置、是否允许超支及上限、提醒开关与阈值、优先级、是否强制、状态、备注、版本号。

**FR-7.6.3** 提供分配管理弹层，支持增删改与分配汇总。

**FR-7.6.4** 分配状态：`active`（启用）、`inactive`（停用）。

**FR-7.6.5** 分配编辑表单字段：分配金额、分类、成员（可选「不限成员」）、「单独提醒」开关与提醒阈值（说明：为这个分配项单独设置提醒阈值）、「必需项」开关（说明：适合房租、保险、固定还款等刚性预算）、备注。

**FR-7.6.6** 分配弹层上方展示「预算总额 / 已分配」汇总，用于判断是否超额分配。

### 7.7 预算表单

**FR-7.7.1** 表单字段：所属账本、预算名称、跟踪类型、匹配范围、分类与子分类、账户范围、标签、预算周期、一次性起止日期、金额、备注、颜色、提醒阈值、自动结转。

**FR-7.7.2** 选择「一次性」时显示起止日期，并隐藏「自动结转」。

**FR-7.7.3** 标签从候选列表中选择。

**FR-7.7.4** 预算卡片展示：进度环、已用/剩余、使用率、分配概览（分配项数、已分配）、接近阈值项数、账本徽标；操作：查看流水、预算历史、预算分配、编辑、删除；删除确认提示「流水不会被删除」。

### 7.8 与自动记账的衔接

**FR-7.8.1** 预算可展示「待入账金额」：周期内命中预算作用域、已到点但尚未入账的自动记账金额合计。

## 8. 分期计划

### 8.1 目标

管理信用账户的分期消费，冻结额度并按期生成账单流水。

### 8.2 计划与明细字段

**FR-8.2.1** 计划字段：名称、说明、账户、分类与子分类、总本金、总利息、总期数、剩余期数、每期金额、币种、起始日、结束日、首次到期日、状态、利率（基点）、利息总额、计算方式、备注、所属账本、版本号。

**FR-8.2.2** 每期明细字段：所属计划、账户、期号、金额、本金、利息、到期日、实付日、状态、关联流水、备注、版本号。

| 计划状态 | 取值 | 明细状态 | 取值 |
| --- | --- | --- | --- |
| 进行中 | `active` | 待入账 | `pending` |
| 已完成 | `completed` | 已入账 | `posted` |
| 已取消 | `cancelled` | 已跳过 | `skipped` |

### 8.3 创建规则

- **BR-8.3.1** 分期只能挂到信用型账户。
- **BR-8.3.2** 创建时冻结本金额度，并校验不超过信用额度。
- **BR-8.3.3** 分类必须为支出分类。
- **BR-8.3.4** 本金与利息按期数平均分摊，余数分配到前几期。
- **BR-8.3.5** 每期到期日按首次到期日逐月递增。
- **BR-8.3.6** 结束日为首次到期日加上（期数 − 1）个月；每期金额为总应还除以期数后向上取整。
- **BR-8.3.7** 默认采用「等额平摊」（`flat`）计算方式。
- **BR-8.3.8** 同一计划的期号唯一。

**FR-8.3.9** 分期表单字段：名称（最多 40 字）、入账日（首次到期日，范围约为昨天至 10 年后）、信用账户、支出分类与子分类、计算方式（等额平摊 / 等额本息 / 等额本金）、本金、期数（不超过 120）、总利息（等额平摊）或年利率（等额本息 / 等额本金，0–100%）、备注。

**FR-8.3.10** 表单实时估算：等额平摊显示「每期约还 ¥X（含利息 ¥Y）」；等额本息显示「每期约还 ¥X（总利息 ¥Y）」；等额本金显示「首期约还 ¥X，逐期递减（总利息 ¥Y）」。

**BR-8.3.11** 计算方式：
- **等额平摊**：本金与总利息分别均摊，余数分配到前几期；
- **等额本息**：每期还款额相同，利息按剩余本金与月利率（年利率 ÷ 12）计算；
- **等额本金**：每期本金相同，利息按剩余本金与月利率计算，每期金额逐期递减。

**BR-8.3.12** 计算方式为等额本息 / 等额本金时必须提供年利率（基础点存储），否则校验失败；各期本金之和严格等于总本金。

### 8.4 入账

**FR-8.4.1** 到期明细可自动批量入账，也可手动单期入账。

**FR-8.4.2** 入账时生成一条支出流水（金额 = 本金 + 利息），关联计划账户与分类，并回填明细状态与实付时间。

- **BR-8.4.3** 入账同时释放该期本金冻结额度，并把该期金额计入已用负债。
- **BR-8.4.4** 分期入账流水不可编辑、删除或退款。
- **BR-8.4.5** 全部期数入账后计划自动标记为已完成，剩余期数归零。

**FR-8.4.6** 分期明细弹层按到期顺序列出每期：期号、应还、本金、利息、状态；未入账期提供「入账」操作，入账前二次确认「确认将第 N 期生成支出流水？」；已入账期可跳转查看对应流水。

### 8.5 取消

**FR-8.5.1** 仅进行中的计划可取消。

- **BR-8.5.2** 取消时释放未入账期的本金冻结额度，未入账明细标记为已跳过，计划标记为已取消，剩余期数归零。
- **BR-8.5.3** 已入账期不受影响。

### 8.6 状态修复

**FR-8.6.1** 打开分期列表时，系统根据明细入账进度自动修复计划的剩余期数与状态（已完成/进行中），已取消计划跳过。

## 9. 自动记账

### 9.1 目标

按固定周期自动生成收入或支出流水，适用于房贷、房租、会员订阅等固定开销。

### 9.2 模板字段

**FR-9.2.1** 模板字段：名称、类型（收入/支出）、金额、币种、描述、备注、商家、账户、分类与子分类、支付方式与自定义名称、实际付款标记、所属账本、执行频率、执行日（月内日或周内星期）、执行时间（当天分钟数）、开始日期、结束日期、启用状态、版本号。

| 频率 | 取值 | 调度参数 |
| --- | --- | --- |
| 每天 | `daily` | 每天 |
| 每周 | `weekly` | 周内星期（1=周一 … 7=周日） |
| 每月 | `monthly` | 月内日（超过当月天数时取当月最后一天） |

**FR-9.2.2** 模板列表支持搜索、新增、编辑、删除、立即执行。

### 9.3 执行机制

**FR-9.3.1** 到点后自动执行到期任务；也支持对单个模板「立即执行」。

**FR-9.3.2** 系统从模板开始日期起按频率推进，生成截至当前的全部到期任务，且不超过模板结束日期。调度时间包含配置的当天时间。

**FR-9.3.3** 去重：同一用户、同一模板、同一次到期任务只入账一次，唯一键为「用户 + 模板 + 到期标识」。

**FR-9.3.4** 执行记录字段：所属模板、到期标识、状态、关联流水、计划执行时间、实际入账时间、模板版本号、错误码与错误信息。执行结果状态：

| 状态 | 取值 | 说明 |
| --- | --- | --- |
| 待执行 | `pending` | 已到点尚未入账 |
| 已入账 | `posted` | 成功生成流水 |
| 重复跳过 | `duplicate_ignored` | 已存在同任务流水 |
| 已拦截 | `blocked` | 数据校验不通过，需处理后重试 |
| 可重试失败 | `retryable_failed` | 临时性错误，下次自动重试 |
| 用户已删除 | `user_deleted` | 由该任务生成的流水被用户删除 |

- **BR-9.3.5** 触发拦截的情况：账户、分类或账本不存在，金额非法，账户类型不符，账户余额非法，余额不足，信用额度不足。
- **BR-9.3.6** 其它错误标记为「可重试失败」。
- **BR-9.3.7** 用户可「重置」已拦截任务，使其重新校验并入账。
- **BR-9.3.8** 自动记账生成的流水标注来源任务；删除该流水后，对应任务标记为「用户已删除」。
- **BR-9.3.9** 多个执行入口并发时，只有一方入账，其余跳过。

**FR-9.3.10** 模板卡片展示执行记录历史：每条记录的状态（已入账/待执行/重复跳过/已拦截/可重试失败/用户已删除）、计划时间、实际入账时间、错误信息；对「已拦截 / 可重试失败」提供「重置」操作，重置后下次执行重新校验。

**FR-9.3.11** 「立即执行」结果以汇总提示：入账 N 笔、跳过 N 个未到期、拦截 N 笔、失败 N 笔。

**FR-9.3.12** 模板可启用/停用。删除模板确认提示「已经生成的流水不会被删除」。

### 9.4 与其它功能的联动

- **BR-9.4.1** 自动记账入账后刷新预算进度、信用还款提醒与使用记录。
- **BR-9.4.2** 预算的「待入账金额」引用未入账的自动记账任务。

**FR-10.2.8** 待处理数量显示在「更多」面板的提醒入口角标上。

- **BR-10.2.9** 事项以「来源类型 + 来源 ID + 到期日」唯一标识，处理状态按该标识持久化，同一事项只出现一次。

## 11. 统计与分析

### 11.1 统计口径

- **BR-11.1.1** 只统计已完成的收入与支出，排除转账。
- **BR-11.1.2** 只统计属于当前账本的流水。
- **BR-11.1.3** 按有效金额（扣除退款）计算。
- **BR-11.1.4** 只按主导币种汇总，并提示是否存在混合币种。

### 11.2 时间周期

| 预设 | 说明 | 分组 |
| --- | --- | --- |
| 本月 | 当月自然月 | 按日 |
| 本周 | 本周一至周日 | 按日 |
| 上周 | 上周一至周日 | 按日 |
| 近 3 个月 | 含本月往前共 3 个自然月 | 按月 |
| 今年 | 当年自然年 | 按月 |
| 自定义 | 用户选择起止 | 跨度不超过 93 天按日，否则按月 |

**BR-11.2.1** 自定义区间为「含开始、不含结束」。
**BR-11.2.2** 支持与上一周期（等长前移）和去年同期对比。

### 11.3 统计筛选

**FR-11.3.1** 筛选维度：时间周期、自定义区间、账户、账户类型、支付方式、类型视角（收支/支出/收入）。

**FR-11.3.2** 切换账本时重置账户、类型、支付方式筛选。

**FR-11.3.3** 支持一键重置全部筛选（保留用户自定义的异常阈值）。

### 11.4 汇总指标

**FR-11.4.1** 总览：总收入、总支出、净额、收支笔数、平均每笔收支，以及与上期、去年同期的对比。

**FR-11.4.2** 一句话结论：如「支出 ¥X · 较上期 ↑Y% · 最大头是 A（¥Z，N%）· K 项异常波动」；隐藏金额时显示占位符。

- **BR-11.4.3** 结论语气：支出下降或收入上升为正面，反之为负面，持平或无基准为中性。

### 11.5 分析内容

**FR-11.5.1** 收支趋势图（按日/按月）。
**FR-11.5.2** 支出/收入分类占比图，可点击跳转对应流水。
**FR-11.5.3** 二级分类排行。
**FR-11.5.4** 商家排行。
**FR-11.5.5** 标签排行。
**FR-11.5.6** 支付渠道分布（金额、占比、笔数、收支拆分）。
**FR-11.5.7** 账户与支付渠道交叉排行。
**FR-11.5.8** 消费时段分布（清晨、上午、下午、晚上、深夜）。
**FR-11.5.9** 星期分布（含周末标记）。
**FR-11.5.10** 来源拆分（分期、自动记账、其他）与来源趋势。
**FR-11.5.11** 退款汇总（笔数、金额、退款率）。
**FR-11.5.12** 信用卡额度使用率。
**FR-11.5.13** 账户分布与账户类型分布（资产/负债、占比、账户数）。
**FR-11.5.14** 家庭账本成员参与（已付、参与、净额、笔数）。
**FR-11.5.15** 待付账单。
**FR-11.5.16** 未来现金流（30 天、90 天、每月固定支出）。
**FR-11.5.17** 净资产趋势（默认近 90 天，来自每日资产快照）。
**FR-11.5.18** 预算执行与预算历史趋势。

### 11.6 消费异常检测

**FR-11.6.1** 对分类、子分类、商家三个维度，比较当前窗口与基准期的金额增长。

- **BR-11.6.2** 默认参数：基准 3 个月、当前窗口 1 个月、最低金额 5000 分（¥50）、最低增幅 20%。
- **BR-11.6.3** 仅当当前金额达到最低金额、基准均值大于 0、增幅超过阈值时识别为异常；按增幅降序、金额降序取前 20 条。

**FR-11.6.4** 用户可调整异常检测的最低金额与最低增幅。

**FR-11.6.5** 提供「消费变化阈值」设置弹层；卡片展示触发项及其增长百分比，未触发时提示「暂无明显消费变化」。

### 11.7 分析报表

**FR-11.7.1** 报表按账本与周期（`weekly` / `monthly` / `quarterly` / `yearly`）生成。

**FR-11.7.2** 报表快照内容：收入、支出、净额、分类支出、Top 商家、分期金额、自动记账金额、预算使用率、超支预算数、币种。

**FR-11.7.3** 报表字段：范围类型、所属账本、报表周期、周期起止、状态、报表内容、开始生成时间、完成时间、失败信息。

**FR-11.7.4** 报表状态：`generation_started`（生成中）、`completed`（已完成）、`failed`（失败）。

- **BR-11.7.5** 生成前清理同账本同周期遗留的「生成中」记录，避免长期卡在生成状态。

**FR-11.7.6** 展示最近一次完成的报表；若最近一次失败则展示失败信息。

**FR-11.7.7** 支持按账本配置自动生成周报/月报/季报/年报，默认仅月报开启。

**FR-11.7.8** 支持在报表卡片切换周报 / 月报 / 季报 / 年报，并按所选周期生成与展示；周期区间：周报为本周一至周日、月报为自然月、季报为自然季、年报为自然年。

**FR-11.7.9** 报表卡片标题「分析报表 · {周期}收支报告」，展示收入、支出、净额、预算执行率等摘要；未生成时提示「生成{周期}后，这里会显示收支摘要」并提供生成按钮，生成中禁用按钮。

**FR-11.7.10** 报表卡片提供「自动生成设置」入口，按账本配置周报 / 月报 / 季报 / 年报是否自动生成（默认仅月报开启）；进入统计页时按配置补齐当前周期的报表。

### 11.8 统计页结构

统计页分 5 页：

1. **概览**：总额、趋势、消费异常；
2. **支出**：分类、二级分类、商家、标签排行；
3. **渠道**：支付渠道、账户渠道、时段与星期、来源拆分；
4. **预算**：预算执行、预算历史趋势；
5. **账户**：账户分布、账户类型、额度使用、净资产趋势、待付账单、未来现金流、成员参与、分析报表。

## 12. 分摊与家庭账本

### 12.1 分摊记录

**FR-12.1.1** 仅家庭账本支持分摊，且只能对已完成的支出流水分摊。

- **BR-12.1.2** 同一流水同一时间只允许一个有效分摊记录。

**FR-12.1.3** 分摊会同时把该流水加入家庭账本。

**FR-12.1.4** 分摊方式：

| 方式 | 取值 | 规则 |
| --- | --- | --- |
| 均摊 | `equal` | 按参与人数平均分配，余数分配到前几项 |
| 固定金额 | `fixed_amount` | 各参与者金额之和等于总金额 |
| 按比例 | `percentage` | 各参与者比例之和为 100%（10000 基点） |

**FR-12.1.5** 分摊记录字段：所属账本、关联流水、状态（有效/已取消）、分摊方式、总额、币种、付款人、备注、版本号；明细字段：成员、金额、比例、备注。

- **BR-12.1.6** 付款人可以不参与分摊，但必须是账本成员；所有参与者必须是账本成员。

**FR-12.1.7** 分摊操作：创建、替换（取消旧记录并新建）、取消。

**FR-12.1.8** 分摊弹层支持：选择分摊方式、从已有模板一键「应用模板」并「管理模板」、选择付款人、内联「添加成员」、勾选参与成员并填写金额或比例、备注。当成员少于两人时提示「至少需要两个成员」。

### 12.2 分摊规则

**FR-12.2.1** 规则仅属于家庭账本。

**FR-12.2.2** 规则类型：`equal`（均摊）、`percentage`（按比例）、`fixed_amount`（固定金额）、`weighted`（加权）、`custom`（自定义）。

**FR-12.2.3** 规则字段：名称、类型、配置内容、启用状态、优先级（默认 0）、所属账本。

**FR-12.2.4** 提供规则管理弹层，支持增删改。

### 12.3 成员参与统计

**FR-12.3.1** 统计家庭账本各成员的已付金额与笔数、参与金额与次数、净额（已付 − 参与）。

## 13. 账本与成员

### 13.1 账本

**FR-13.1.1** 账本分个人账本（`personal`）与家庭账本（`family`）。

**FR-13.1.2** 账本字段：名称、说明、创建成员、类型、状态、基准币种、结算周期与结算日、图标、颜色、版本号。

- **BR-13.1.3** 每个用户默认拥有「个人账本」，不可删除、不可解绑。
- **BR-13.1.4** 家庭账本在仍有有效分摊关联时不能删除。
- **BR-13.1.5** 家庭账本的流水可加入或移出；个人账本不支持解绑。

### 13.2 账本切换

**FR-13.2.1** 顶部展示当前账本，可切换；切换后各面板按新账本重新取数。

**FR-13.2.2** 窄屏时通过弹层切换账本。

**FR-13.2.3** 账本操作：新增家庭账本、删除家庭账本、管理账户、管理成员。

**FR-13.2.4** 账本切换弹层展示当前账本摘要（名称 + 个人/家庭）与账本列表，并提供「成员 / 账户 / 新增家庭账本 / 删除该家庭账本」入口。

**FR-13.2.5** 新建家庭账本弹层填写账本名称（示例：家庭账本）。

### 13.3 成员

**FR-13.3.1** 成员字段：名称、角色、状态、头像、颜色、版本号。

**FR-13.3.2** 角色分成员（`participant`）与管理员（`manager`）。

**FR-13.3.3** 成员操作：添加、编辑、删除。

**FR-13.3.4** 成员管理弹层支持添加/编辑/删除成员；成员字段含名称与角色（成员/管理员）；删除确认提示「删除后该成员在本账本中将不可用」。

**FR-13.3.5** 账本账户管理弹层用于把账户加入/移出当前家庭账本。

### 13.4 数据隔离

- **BR-13.4.1** 流水与统计按账本过滤。
- **BR-13.4.2** 预算、分期、自动记账、账单提醒按所属账本查询（默认账本兜底归属为空的记录）。
- **BR-13.4.3** 账户按账本关联过滤。
- **BR-13.4.4** 切换账本后重置统计的账户、类型与支付方式筛选。

## 15. 消息通知

### 15.1 预算提醒

**FR-15.1.1** 到达提醒阈值时推送「预算已达 N%」；达到 100% 时，支出限额推送「预算已达 100%」，收入目标推送「收入目标已达 100%」。

- **BR-15.1.2** 同一阶段只推送一次；阶段推进（如从 80% 到 100%）时再次推送。
- **BR-15.1.3** 支持按天「延后提醒」，延后期间不再推送。

### 15.2 账单提醒

**FR-15.2.1** 到达「到期日 − 提前提醒天数」后推送，文案含到期或逾期天数与金额。

- **BR-15.2.2** 逾期后每天重新推送，直到用户处理或到期日变化。
- **BR-15.2.3** 信用还款提醒的金额取账户当前负债；金额为 0 时不推送。

### 15.3 每日汇总

**FR-15.3.1** 每日汇总待处理提醒数量并推送。

### 15.4 触发时机

- **BR-15.4.1** 预算、提醒、交易数据变更后自动触发对应提醒扫描。
- **BR-15.4.2** 通知发送失败（如未授权）不影响正常使用，仅记录日志。

## 16. 多设备同步与冲突处理

### 16.1 增量同步

**FR-16.1.1** 记账数据支持多设备同步与备份，采用增量方式，只传输发生变化的记录。

**FR-16.1.2** 变更依据「变更日志 + 版本号 + 设备标识」判定；本地变更写入日志，远端变更按日志应用。

**FR-16.1.3** 同步与备份支持加密。

### 16.2 流水冲突

**FR-16.2.1** 当同一笔流水在多设备被同时修改且产生冲突时，用户可选择保留本地或远端，并支持按字段组分别选择：
- 可选择远端的字段组：记录信息、基础信息、账户、分类、文本；
- 不可逐字段选择、需整体取舍：账本、分摊、分期、删除状态。

**BR-16.2.2** 字段合并后按正常更新流程写回。

**BR-16.2.3** 转账交易冲突不支持逐字段合并，需整体选择一方。

### 16.3 其它实体冲突

**FR-16.3.1** 非流水实体（账户、分类、预算等）冲突时，支持整体选择保留本地或采用远端。

**FR-16.3.2** 选择远端时应用远端变更；选择本地时保留本地并标记冲突已解决。

## 17. 通用交互与体验要求

### 17.1 离线可用

**NFR-17.1.1** 所有记账功能在无网络时完整可用，数据以本地为准。

**NFR-17.1.2** 未解锁状态下不读取任何记账数据。

### 17.2 性能与加载

**NFR-17.2.1** 流水与账户列表采用分页加载，避免一次性加载。

**NFR-17.2.2** 面板按需加载并保持状态，首屏只加载必要数据。

**NFR-17.2.3** 数据变化引起的界面刷新应合并处理，避免整页反复重建。

**NFR-17.2.4** 需要频繁筛选的字段（用户与时间、用户与账户、用户与分类、用户与状态、用户与支付方式等）建立查询索引。

### 17.3 数据完整性

**NFR-17.3.1** 流水写入、余额更新、账本关联、预算刷新等关联操作应作为一个整体完成，避免半完成状态。

**NFR-17.3.2** 自动记账、预算快照、提醒等需保证不重复生成（通过唯一性约束保障）。

### 17.4 响应式与可用性

**NFR-17.4.1** 宽屏与窄屏自适应：宽屏使用详情侧栏，窄屏使用弹窗或底部弹层。

**NFR-17.4.2** 关键操作有轻提示反馈；破坏性操作需二次确认。

**NFR-17.4.3** 支持浅色与深色主题，金额按中文本地化格式展示。

**NFR-17.4.4** 金额隐藏状态在各页面保持一致。

### 17.5 安全与隐私

**NFR-17.5.1** 记账数据属于敏感数据，受解锁与应用锁保护。

## 25. 附录：边界与异常场景

### 25.1 账户
- 资产账户余额不足 → 支出/转出失败，提示「账户余额不足」。
- 信用额度不足 → 支出/转账/分期失败，提示「信用账户占用额度不能超过信用额度」。
- 停用/删除账户后，历史流水仍可见（账户显示为不可用）。
- 编辑账户改变类型或初始余额时按规则调整余额与额度（见 4.3）。

### 25.2 流水
- 编辑时更换账户：先在旧账户回滚，再在新账户应用；余额分别校验。
- 退款后编辑金额：退款额自动收敛到新金额以内；退款不得为负。
- 删除流水：回滚账户余额；由自动记账生成的流水删除后对应运行记录置为「用户已删除」。
- 分期入账流水：只读，不可编辑/删除/退款。
- 转账：两条必须匹配（金额、时间、互指、方向）；不匹配时视为非法。

### 25.3 分类
- 删除分类后，历史流水保留但显示「分类不可用」。
- 内置分类可重排但仅本设备生效；自建分类重排会同步。
- 分类名称重名被拒绝。

### 25.4 预算
- 一次性预算未填日期或结束早于开始 → 校验失败。
- 账单周期预算未指定账户 → 不支持该周期。
- 自动结转仅循环周期生效；超支不冲减下期。
- 标签预算不命中任何交易时，不报错，仅已用为 0。

### 25.5 分期
- 非信用账户不可建分期；额度不足时创建失败。
- 非进行中计划不可取消；取消释放未入账本金冻结。
- 发票日期超过 10 年范围被拒绝。

### 25.6 自动记账
- 余额不足/账户或分类不可用/额度不足 → 拦截；其它错误 → 可重试失败。
- 重置后下次执行重新校验；并发执行只入账一次。
- 删除模板不影响已生成流水。

### 25.7 提醒
- 重复提醒过期后滚动到下一次生效到期日。
- 信用还款金额为 0 时不推送。
- 逾期后逐日复推，直到用户处理或到期日变化。

### 25.8 分摊
- 成员不足 2 人不能分摊。
- 一条流水只能有一个有效分摊；重复创建被拒绝。
- 个人账本不可分摊；有有效分摊的家庭账本不可解绑。

### 25.9 统计
- 混合币种时按主导币种汇总并提示。
- 区间无数据时展示空态，不报错。

## 26. 附录：关键用户流程

> 以下流程用于验收；括号内为预期结果。

1. **记录一笔支出**：选择支出 → 填写金额/账户/分类/支付方式 →（余额减少对应金额；预算刷新；可继续记下一笔）。
2. **记一笔转账**：选择转出与转入账户（可一键交换）→ 填写金额 →（生成成对转账，两账户余额同步变化）。
3. **登记退款**：打开已完成支出详情 → 退款 → 填写金额（不超剩余可退）→（账户余额回补，统计按有效金额更新）。
4. **转为分期**：录入支出时选择「转为分期支付」→ 在分期表单补全期数与利息 →（创建分期计划并冻结本金；关闭记账表单）。
5. **家庭分摊**：选择家庭账本 → 设置分摊（可套用模板）→ 选择付款人与参与成员 →（流水加入家庭账本；生成有效分摊记录）。
6. **新建预算并分配**：新建预算 → 选择周期/范围/金额 → 打开分配 → 添加分配项 →（预算卡片显示进度；分配汇总正确）。
7. **信用卡还款**：进入信用卡账单 → 账单核对 → 还款 →（转账表单预填转入与金额，提交后应还减少）。
8. **信用卡补记差额**：账单核对 → 补记差额 →（生成一笔不计入收支统计的补记流水，账单对齐）。
9. **配置自动记账**：新建模板 → 设定频率与执行日 →（到期自动入账；可在执行记录看到状态并可重置）。
10. **处理提醒中心**：打开提醒 → 完成/延后/忽略（可多选批量）→（列表与角标更新，历史可查）。
11. **统计下钻**：统计页点击分类/商家/渠道 →（跳转到帯对应筛选的流水列表，可一键清除）。
12. **切换账本**：切换账本 →（各面板按新账本重新取数；统计的账户/类型/支付方式筛选重置）。

## 27. 附录：界面状态规范

- **加载态**：列表/卡片使用骨架屏；局部刷新不清空已有内容。
- **错误态**：展示「读取××失败」并提供重试；重试重新加载对应数据。
- **空态**：各列表提供空态文案与行动入口，例如：
  - 流水：「还没有流水 / 此时间范围内没有交易记录」+「记一笔」；
  - 账户：「还没有账户 / 暂无匹配账户」+「新增账户」；
  - 分类：新增分类 / 清除搜索；
  - 预算：新增预算 / 无匹配预算；
  - 分期：无信用账户/无支出分类/无计划，分别给出引导入口；
  - 自动记账：新增模板；
  - 提醒：新增提醒 / 暂无待处理；
  - 统计：各卡片独立空态（如「暂无账户分布数据」）。
- **金额遮罩态**：开启隐藏金额后，所有金额展示为占位符，不影响交互。
- **确认态**：删除、取消分期、分摊替换等破坏性操作二次确认。

## 29. 附录：性能与容量预算

- 流水列表分页 20 条/页，账户列表 8 条/页，避免一次性加载。
- 统计查询按账本与日期范围过滤，并使用相应索引。
- 首页只看所需数据；未解锁不读数据。
- 数据刷新在同一事件循环内合并为一次。
- 预取范围限定为首屏必需数据（账本/当前账本/可见账户/月度汇总/支出与收入分类/流水首页）。
- 大量交易下按日/月分组聚合，避免逐条渲染。
